## Implémentation

La table dans **`back/runtime/besoin/proposes.go`** (au-dessus de la grammaire EL02) :

- **Types** — `MappingKind` ∈ {`MappingEmit`, `MappingNoEmit`}. `Mapping{Kind, Proposes(ideas.Proposes)}` est une struct **comparable** (l'égalité, donc la reproductibilité, se teste directement) : `Proposes` n'est rempli que pour `MappingEmit`, vide pour `MappingNoEmit`.
- **La table déclarée** — `levelProposesTable map[Level]Mapping` est **first-class, close, totale**, son domaine est **exactement `AllLevels()`** (9 entrées). Les 5 rungs SOURCE dont le nom est un `ProposesKind` (`control/action/operation/entity/product`) + la bande `policy` se mappent vers eux-mêmes (`emit(ideas.ProposesX)`) ; `journey`, `view`, `invariant` sont `noEmit`. Chaque ligne porte un commentaire renvoyant à l'ADR 0041.
- **Les fonctions autoritaires** — `LevelToProposes(l) → Mapping` (pure, totale ; pour un niveau hors-grammaire renvoie `noEmit` afin que l'itération sur les niveaux valides ne panique jamais) ; `LevelToProposesChecked(l) → (Mapping, error)` (erreur **dure** sur hors-grammaire — un mapping vers un kind inconnu est impossible) ; helpers `NoEmitLevels()`, `EmitLevels()`, `IsNoEmit(l)`.

**Miroir property** (`proposes_property_test.go`, rapid) — écrit ROUGE d'abord (les symboles `LevelToProposes`/`MappingEmit`/… n'existaient pas), puis VERT :
- `TestLevelToProposes_TotalOverAllLevels` : chaque niveau valide mappe vers exactement un `Mapping` ; un Emit a un `Proposes` non vide, un NoEmit a un `Proposes` vide ;
- `TestLevelToProposes_EmitTargetIsInClosedSet` : **chaque** cible Emit est membre de `ideas.ProposesKinds()` (la jointure honnête, jamais un kind inventé) ;
- `TestLevelToProposes_NoSilentAlias` : les 6 niveaux self-kind mappent vers **leur propre** kind ; `journey`/`view`/`invariant` sont **forcément** NoEmit (jamais aliasés) ;
- `TestLevelToProposes_NoEmitSetIsExact` : le set NoEmit est **exactement** `{journey, view, invariant}` ;
- `TestLevelToProposes_OutOfGrammarIsHardError` : sur des chaînes aléatoires hors-grammaire, `LevelToProposesChecked` renvoie **toujours** une erreur ;
- `TestLevelToProposes_Reproducible` : même niveau → même `Mapping` sur 50 appels (déterminisme) ;
- `TestLevelToProposes_DomainIsExactlyAllLevels` : le domaine de la table ≡ `AllLevels()`, aucune entrée en trop ni manquante.

## Méta

Le geste d'EL05, c'est **joindre honnêtement deux grammaires fermées de cardinalités différentes** (9 niveaux ↔ 6 kinds) sans en distordre aucune. Trois disciplines KRD s'y croisent :

- **Déterminisme-first (§6/§8)** : le mapping est une **fonction pure totale sur un set déclaré**, jamais un « choix de convenance » LLM. La property de reproductibilité (`même niveau → même mapping`) est l'application littérale du mandat « tout ce qui peut être une fonction pure DOIT être du code ».
- **Anti-Goodhart (§8)** : le danger n'est pas qu'un niveau ne mappe pas — c'est qu'il mappe **faussement** (un cast silencieux `journey→product` qui gonflerait le compteur d'Ideas). La table refuse l'alias **par construction** (self-map seul) et le prouve par property, pas par convention.
- **Le mur (§2)** : EL05 décide une **cible**, jamais une **émission**. Elle joint vers `ideas.ProposesKinds()` (un closed set du Kernel) sans **l'élargir** — élargir ce set serait un changement de vérité (idée → miroir → /goal), pas une décision de track above-the-wall.

## Méta-méta

EL05 est la **charnière de typage** entre le track « compound du besoin » (above-the-wall) et l'app-builder (below-the-wall) : elle dit, pour chaque rung de l'architecture, **quel genre de candidate** il deviendra — ou s'il ne devient **rien** (NoEmit, il seede). C'est ce qui permet à EL16/EL17 de produire un backlog d'Ideas **topo-trié** où chaque Idea porte déjà son `Proposes` correct et où les nœuds qui ne portent qu'une contrainte (journey/view) restent des **ancres**, jamais de faux items. La leçon récursive : **on n'étend pas un closed set pour faire rentrer une grammaire voisine ; on déclare la jointure, on la prouve close et alias-free, et on nomme `NoEmit` ce qui n'a pas de cible** — l'honnêteté de la topologie est plus précieuse qu'une complétude apparente. C'est le même principe qui, plus tard, empêchera l'app-builder de croire qu'un écran (`view`) « est » un produit.
