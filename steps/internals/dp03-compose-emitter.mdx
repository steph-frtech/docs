## Implémentation

### Le miroir d'abord (rouge → vert)

`back/runtime/composeemit/composeemit_property_test.go` est écrit **avant** tout code non-test — rouge au premier run (`no non-test Go files`), vert ensuite. Neuf lois ∀ (rapid), sur un générateur de manifests **valides** (noms uniques, ports uniques, `services[0]` forcé `role=server`, rôles/profils tirés des ensembles clos de DP02) :

1. **Reproductibilité ∀** — `Emit(m)` deux fois → octets identiques ; et ×100 sur le manifest `Example()` épinglé (100 %, pas 99 %).
2. **Routeur serveur** — tout `role=server` émet `websecure`, `tls=true`, `certresolver=$CERT_RESOLVER_NAME` et le middleware `$APP_NAME-https-redirect`.
3. **Bind volume** — chaque volume émet `device: $DEVICE_VAR` (la référence d'env-var, forme littérale `${DEVICE_VAR}` dans les octets) + `type: none` + `o: bind`.
4. **Réseau** — `external: true` ssi `network.external` (le déploiement qui POSSÈDE `traefik_default` ne le marque pas externe) ; le nom concret est toujours `$TRAEFIK_NETWORK_NAME`.
5. **Aucun port publié** — la clé `ports:` n'apparaît jamais.
6. **Refus** — un manifest cassé (rôle inconnu / port dupliqué / sans serveur) → `BlockReason` actionnable, zéro octet émis.
7. **Drift** — un octet inversé → `Drifted(output_hash, bytes)` vrai ; l'émission intacte → faux.
8. **Double adresse** — `SourceHash == stackmanifest.HashManifest(m)` (S02 réutilisé, jamais forké), `OutputHash == records.Hash(bytes)`, header protégé `# CODE GENERATED BY AIDOS — DO NOT EDIT. source: <hash>`, chemin `back/gen/<app>/docker-compose.yml`, `TargetDockerCompose` enregistré en dernier de `targetOrder`.
9. **Conventions par service** — `container_name: $APP_NAME` (serveur primaire), `restart: unless-stopped` et `env_file: .env` exactement une fois par service.

### Le package pur

`back/runtime/composeemit/composeemit.go` : `TargetDockerCompose = "docker-compose"` déclaré dans **son** `targetOrder` (le motif additif de `honoemit`/`apisurface`/`frontemit` — chaque émetteur possède ses targets, la matrice globale reste l'union énumérable). `Emit(m)` : `stackmanifest.HashManifest` (validation pure DP02 incluse — un manifest invalide n'a pas d'adresse) → `render(m, sourceHash)` → `Artifact{Path, Target, Kind, Bytes, SourceHash, OutputHash, Protected}`. Le rendu : `sortedServices` (ordre stable par nom), `primaryServer` (premier `role=server` trié — `$APP_NAME` nu ; les autres serveurs prennent le sous-sous-domaine `<svc>.$APP_SUBDOMAIN.$DOMAIN`, le motif `api.` du boilerplate nodejs), `renderTraefikLabels`, `renderHealthcheck` (cadence boilerplate 30s/3s/3/10s), `renderNetworks`, `renderVolumes` (un seul volume → `name: $APP_NAME`, le modèle boilerplate ; plusieurs → suffixés), fold `strings.Join`, newlines `\n`, aucune horloge/RNG/map-order. `Drifted` **réutilise** `generators.Drifted` (S34) verbatim.

### Le jumeau TS épinglé

`front/web/lib/stack-emit.ts` : `renderCompose`/`emitCompose`/`driftDetected`, jumeaux octet-pour-octet du Go autoritatif. Le miroir vitest (`lib/stack-emit.test.ts`, 10 tests, fast-check) épingle `GO_OUTPUT_HASH = efea2247cc86…6fea24c1` et `GO_SOURCE_HASH = 8011728e4f9c…62acdd2` (== le `GO_MANIFEST_HASH` de DP02 — l'émetteur réutilise l'adresse du kernel) : toute divergence d'un octet rougit. Vitest complet : **2080/2080** (baseline 2070 intacte, anti-overwrite).

### L'écran et la preuve e2e

Route `/stack-emit` (thème ADR 0010, bilingue ADR 0011, entrée nav après `/stack-manifest`) : le compose seedé émis du manifest `Example()`, les deux hashs Go-épinglés, la matrice kind × target affichée, et **UN contrôle** « émettre le compose (n'écrit rien) » — server action **mesure pure** sur textarea contrôlé. E2e Playwright `tests/e2e/stack-emit.spec.ts` **4/4** sur le port 3210 : conventions visibles + double adresse, ré-émission → **même output_hash**, refus `DUPLICATE_INTERNAL_PORT`, refus `UNKNOWN_SERVICE_ROLE` et `STACK_HAS_NO_SERVER` — tous prouvés **depuis l'écran**. E2e v3 : 16/16, prod :3000 intouchée.

## Méta

- **Pourquoi un package à part et pas un case de plus dans `generators.Emit`** : `generators` émet depuis une `EntitySource` (kind `entity`) ; y enregistrer un target que `render(entity, docker-compose)` ne sait pas produire aurait ouvert un trou (artefact aux octets nuls). Le motif établi par S87/honoemit — *chaque émetteur déclare son `targetOrder`* — garde la matrice close **et** totale : chaque (kind, target) déclaré a un renderer réel.
- **OQ-DP03-emitted-image** : un service à image vide est un service **émis** (construit depuis la phase de l'app, DP05+). Le manifest n'épingle pas encore de référence de registry → l'émetteur rend la **référence d'env-var** `$<SERVICE>_IMAGE` (résolue au déploiement), jamais une valeur inventée. OpenQuestion documentée, résolue quand le pipeline de build (DP05+) fournira l'image.
- **ADR 0043 honoré sans le devancer** : la roadmap v1 faisait du compose l'artefact primaire ; l'ADR le rétrograde en projection du programme Pulumi/TS (`honoemit.TargetPulumiProgram`, déjà émis). DP03 livre donc le compose **comme projection convention `/data/dockers`** — le déployable d'aujourd'hui — sans bloquer la suite Pulumi (DP10 spike-gate).
- **Les messages i18n et les `${VAR}`** : ICU interprète `{VAR}` — les libellés du panneau portent `$APP_NAME` sans accolades ; seuls les octets émis (et les assertions de tests) portent la forme littérale `${APP_NAME}`, avec les suppressions biome explicites (`noTemplateCurlyInString`) là où c'est intentionnel.

## Méta-méta

- **L'émetteur-comme-fonction est le mur côté sortie.** Le mur interdit à l'agent d'écrire la vérité ; le déterminisme-first lui interdit symétriquement d'**improviser la projection**. `Emit` est la preuve constructive que la vérité descend (source → octets) et que rien ne remonte : un fichier émis modifié à la main n'est pas « une variante », c'est une **dérive calculable** — le hash le dit, pas un jugement.
- **La reproductibilité est le contrat social entre les étapes.** DP05 (émission par phase), DP25 (preview) et DP26 (deploy) ne choisiront jamais entre artefacts : ils **ré-émettront**. Ce droit de ré-émettre sans peur repose entièrement sur la loi ×100 gravée ici — même entrée, mêmes octets. Chaque étape DP qui suit hérite de cette pierre angulaire sans avoir à la re-prouver.
- **Trois exécuteurs, une seule vérité de comportement.** Le Go autoritatif, le jumeau TS de l'écran et le YAML que Docker lira sont trois matérialisations du même invariant, cousues par deux hashs. C'est la même structure bicéphale que Kernel/Mirror : quand une copie diverge, ce n'est pas un débat — c'est un miroir qui rougit.
