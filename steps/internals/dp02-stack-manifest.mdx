## Implémentation

**Le package Go `back/kernel/stackmanifest`** (Kernel, pur — zéro DB, zéro I/O) :

- **Les deux ensembles CLOS.** `Roles()` = les 14 rôles du roadmap DP02 (`server datastore cache pooler workflow bus observability errortracking git tickets auth docs connector interpreter` — `workflow` = Windmill, JAMAIS Temporal, spec-2026) ; `Profiles()` = les 9 profils de SPEC-stack-2026 §one-shot (`core docs observability qa git tickets connectors non-prod full`). `IsKnownRole`/`IsKnownProfile` sont des tests d'appartenance sur des listes canoniques — le validateur et le Workbench partagent la même liste, jamais inventée ad hoc.
- **L'AST.** `StackManifest{AppName, Services[]{Name, Role, Image (vide = service ÉMIS, DP03+), InternalPort, Profile, Healthcheck, DependsOn[]}, Volumes[]{Name, DeviceVar — une RÉFÉRENCE d'env-var, jamais un chemin en dur}, Network{Name, External}, ConnectorScopes[]}`. Le manifest déclare ; il ne résout rien (EPIC B).
- **`Validate(m)` pur et total** — les refus fermés, dans l'ordre : `STACK_NAME_REQUIRED`, `SERVICE_NAME_REQUIRED`, `DUPLICATE_SERVICE_NAME`, `UNKNOWN_SERVICE_ROLE`, `UNKNOWN_PROFILE`, `DUPLICATE_INTERNAL_PORT`, puis `STACK_HAS_NO_SERVER`. Chaque refus est une `ValidationError{Code, Message}` actionnable (la discipline BlockReason).
- **Content-addressing = S02 réutilisé, jamais forké.** `CanonicalBody(m)` = `records.Canonicalize(json(body{kind:"stack_manifest", …}))` ; `HashManifest` = `records.Hash(canon)` ; `NewRecord(m)` valide D'ABORD (un manifest invalide n'a jamais d'adresse) puis pose `id == version == hash`. `Record` a la forme 5-colonnes de tout record KRDCore.
- **`Example()`** — le manifest de référence épinglé (convention `/data/dockers` minimale, modèle alphashop) : `app` (server, port 3000, depends_on postgres), `postgres` (datastore, 5432), `interpreter` (le sidecar Go, ADR 0040 D7, port 8973, image vide), volume `app_data → ${APP_DATA_PATH}`, réseau `traefik_default` externe, scope `postgres:read-only`.

**Le miroir property (∀ N1, rapid) — écrit d'abord, rouge (`no non-test Go files`), puis vert.** `stackmanifest_property_test.go`, 8 lois : L1 round-trip content-adressé (`id == version == Hash(Canonicalize(body))`, kind discriminant vérifié) ; L2 reproductibilité ×100 (le miroir de reproductibilité du mandat determinism-first) ; L3 `UNKNOWN_SERVICE_ROLE` (générateur filtré hors ensemble clos) ; L4 `DUPLICATE_INTERNAL_PORT` ; L5 `STACK_HAS_NO_SERVER` ; L6 `STACK_NAME_REQUIRED` ; L7 `UNKNOWN_PROFILE` + les deux ensembles exactement gravés ; L8 sensibilité (un octet logique → nouvelle adresse, append-only).

**La migration Atlas additive** `back/migrations/kernel_stack_manifest_baseline.sql` : `CREATE TABLE IF NOT EXISTS kernel.stack_manifest` (les 5 colonnes KRDCore : id, body JSONB, version, superseded_by, created_at), index sur `body->>'app'`, **le mur** : `GRANT SELECT` + `REVOKE INSERT/UPDATE/DELETE/TRUNCATE` pour `aidos_agent`. Les ensembles clos et la validation sont en CODE (le validateur miroité), délibérément pas en CHECK DB — la convention KRDCore §41–§42 (le body reste inspectable/rejouable). Le miroir d'intégration `migration_roundtrip_test.go` (Testcontainers, postgres:16-alpine) prouve : le record `Example()` round-trip byte-identique dans la table, le SELECT agent passe, **l'INSERT agent est REFUSÉ** (`permission denied`) — le critère « écriture directe refusée ».

**Le jumeau TS `front/web/lib/stack-manifest.ts`** — port pur du validateur + canonicalisation (`compact` = l'omitempty Go ; `encodeCanonical` = clés triées récursivement, zéro espace ; sha256 via `node:crypto` lazy). Le miroir vitest `lib/stack-manifest.test.ts` (10 tests, fast-check inclus) épingle la **parité octet-pour-octet** : `GO_CANONICAL_BODY` (les octets canoniques imprimés par le Go) et `GO_MANIFEST_HASH` (`8011728e4f9c…62acdd2`) sont des constantes — toute divergence d'un octet rougit. Suite front entière : **2070/2070** (baseline 2060+ intacte, anti-overwrite).

**La route `/stack-manifest`** — server component (`exampleManifest()` + `newRecord()` au rendu), panneau client `StackManifestPanel` : la table des services (rôle/image/port/profil/depends_on), volumes/réseau/scopes, l'adresse de contenu, les deux ensembles clos affichés, et **un seul contrôle** « valider & hasher » (`measureAction`, server action) : un textarea **contrôlé** (React possède la valeur — un re-render ne réinitialise jamais l'édition) + le validateur pur → verdict valide (hash + comparaison au seedé : « même body → même hash » ou « nouvelle adresse ») ou refus avec son code. **Mesure pure — rien n'est écrit** (le mur : graver = idée → miroir → /goal). Thème ADR 0010 (tokens), bilingue ADR 0011 (`stackManifest` dans `messages/{fr,en}.json`, FR d'abord), entrée nav `WorkbenchHeader`. E2e Playwright `tests/e2e/stack-manifest.spec.ts` **4/4** (port 3210 ; prod :3000 intouchée) : le manifest seedé + son hash Go-épinglé rendus, le contrôle round-trip (même hash), `DUPLICATE_INTERNAL_PORT` et `UNKNOWN_SERVICE_ROLE`/`STACK_HAS_NO_SERVER` refusés depuis l'écran. Les e2e V3 restent **16/16**.

## Méta

- **Le record-kind a gagné au spike, la migration l'encaisse.** DP01 a scoré 3 formes par critères déclarés — record-kind 4/4. DP02 ne rejoue pas le débat : il crée la table `kernel.stack_manifest` (les 7 kinds KRDCore restent clos — `stack_manifest` est un kind DSL-AST du schéma kernel, comme entity/policy/operation, avec sa propre table et son propre validateur pur).
- **Un manifest invalide n'a jamais d'adresse.** `NewRecord` valide avant de hasher : l'adresse de contenu est un certificat de validité, pas juste une empreinte. Le miroir L3/L4/L5 vérifie les deux côtés (refus du validateur ET refus du constructeur).
- **La parité jumeau par octets, pas seulement par hash.** DP01 épinglait deux hash ; DP02 épingle EN PLUS les octets canoniques complets (`GO_CANONICAL_BODY`) — quand le miroir rougit, le diff montre OÙ le jumeau diverge, pas seulement QUE les hash diffèrent.
- **Le refus est une donnée d'écran.** Les codes fermés (`UNKNOWN_SERVICE_ROLE`…) traversent tels quels : Go → TS → server action → panneau → e2e. Le même mot partout — la langue ubiquitaire jusque dans l'erreur.

## Méta-méta

- **Une vérité naît avec son miroir ou ne naît pas.** Le package n'a pas existé une seconde sans son property test (le rouge initial est littéralement « no non-test Go files ») ; la table n'a pas existé sans son miroir Testcontainers qui prouve le mur. La loi de complétude n'est pas un audit après coup — c'est l'ordre de naissance.
- **Réutiliser le content-addressing au lieu de le recopier est un acte de sécurité.** Si `stackmanifest` avait sa propre canonicalisation, une divergence future entre deux hash « sha256 » serait indétectable. En appelant `records.Canonicalize`/`records.Hash`, tout durcissement de S02 profite au manifest gratuitement — et le miroir L1 le re-prouve à chaque exécution.
- **L'ensemble clos est la forme anti-LLM de l'extensibilité.** Un agent qui rencontre un rôle inédit ne peut pas l'inventer : il doit ouvrir une idée et passer le mur pour étendre `roleOrder` (un changement de vérité, avec SemanticDiff). La frontière entre « deviner » et « proposer » est exactement la frontière entre un enum et un free-string.
- **Le scar React du textarea est gravé en test.** Un `fill()` Playwright qui course l'hydratation peut soumettre des octets fusionnés (manifest + seedé concaténés) ; le remède est double et reproductible : textarea contrôlé côté panneau, helper `setManifestJson` (fill + relecture `toPass`) côté e2e. Le déterminisme s'applique aussi aux tests eux-mêmes.
