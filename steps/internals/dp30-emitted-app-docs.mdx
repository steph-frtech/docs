## Implémentation

### Le paquet — `docsfragments` (nouveau, additif)

DP30 ajoute **UN seul paquet**, `back/runtime/docsfragments/`, **strictement additif** (anti-overwrite §9 — aucun fichier existant n'est touché). Il grave les **docs de l'app émise** — **distinctes** des docs Mintlify d'AIDOS (le journal de build que vous lisez). C'est une tâche **backend-only** : la rangée `docs` de la palette mesurée existe **déjà** côté front (`substrate-palette.ts`, Fumadocs + Scalar + Pagefind, DP14 GO) ; le backend la **casse** en ses trois fragments constituants.

Les trois fichiers (écrits mirror-first — l'impl **après** les deux miroirs) :

- `back/runtime/docsfragments/docsfragments.go` — l'impl.
- `back/runtime/docsfragments/docsfragments_property_test.go` — **9** lois (rapid, N1).
- `back/runtime/docsfragments/docsfragments_fixture_test.go` — **6** fixtures (Godog-class, N2).

### `SubstrateDocsFragments` — casser la rangée « docs » en 3 fragments

```go
func SubstrateDocsFragments(projectID string, env scope.Environment) ([]ServiceFragment, error)
```

La fonction **casse** la rangée `docs` de DP14 en ses **trois fragments constituants** — tous `role docs`, `profile docs`, **images émises** (vides, la convention DP02) :

- **fumadocs** — port `3400`, le **site** de documentation ;
- **scalar** — port `3500`, la **référence API** ;
- **pagefind** — port `3600`, la **recherche statique** (`depends_on fumadocs`).

Chacun porte un **volume bind par-projet** isolé via `datafragments.IsolationToken` — le **token DP15 réutilisé** (les docs d'un projet ne fuient jamais dans un autre). La fonction **fails-close uniquement** sur `UNKNOWN_ENVIRONMENT` — il n'y a **aucun env-gate** : une app a sa doc dans **tous** ses environnements. La mécanique des fragments **calque DP15/16/17/18** (réutilise, ne duplique pas — ADR 0007).

### `EmittedDocs` — la projection PURE (Scalar / Fumadocs / Pagefind)

```go
func EmittedDocs(spec apisurface.ApiSpec) (DocsProjection, error)
```

Le cœur du paquet : une projection **PURE** du Kernel + de l'OpenAPI de S90, qui **n'invente rien** :

- **`Scalar.Endpoints`** : **un** `ScalarEndpoint` par operation **SYNCHRONE** de la surface S90 — via `apisurface.PathOf`, en consommant le chemin `openapi.json` d'`apisurface.EmitOpenAPI`. `createOrder`, `listOrders` sont **rendus** ; une operation **asynchrone** comme `archiveOrder` est **EXCLUE** ; **jamais** un endpoint inventé. Et `SourceHash == apisurface.SourceHash(spec)` — la doc API **est** la surface S90, à la **même adresse** ;
- **`Fumadocs.Pages`** : **une** `FumadocsPage` par entité **distincte** du domaine (les `terms` = nom de l'entité + noms de ses attributs) ;
- **`Pagefind.Records`** : **un** `PagefindRecord` par page (**1:1** avec les pages) ;
- les méta : `DocsID` content-adresse le **corps canonique** ; `Theme = ThemeCcup` (ADR 0010) ; `DefaultLocale = "fr"` + `Locales = [fr, en]` (ADR 0011) ; `IsProjection = true` ; `WroteKernel = false`.

### `SearchIndex` — le « trouve » déterministe

```go
func SearchIndex(idx PagefindIndex, query string) []string
```

Le « trouve » de Pagefind : un **token-match DÉTERMINISTE** — un terme du **domaine** retourne un **hit** ; un terme **hors-domaine** retourne **aucun hit** (la frontière anti faux-positif). Aucun LLM, aucun classement appris — un match de tokens pur.

### Le mur + la validation déléguée

`WritesTruth()` renvoie **`false`** sur **chaque** `ServiceFragment` **et** sur la `DocsProjection` ; **aucune** capability `docs:*` ne matche `IsTruthWriteCapability`. La validation n'est **pas re-frappée** : elle est **déléguée** à `apisurface.EmitOpenAPI` (S90) — si la spec est malformée, le `BlockReason` est **surfacé verbatim** via un `*DocsRefusal` (`AsRefusal`), jamais re-frappé, jamais masqué.

## Méta

- **Le miroir Go est l'épreuve « les docs sont la PROJECTION du Kernel, jamais une invention », ∀.** Le miroir property (rapid, N1) mesure le cœur déterministe en **9 lois**, dont deux **capitales** : `TestL7SameKernelSameDocs` épingle que le **même Kernel** produit des docs **byte-identiques** (la doc ne dérive jamais de l'app), et `TestL8ScalarConsumesEveryEndpoint` épingle que **chaque** operation synchrone de S90 est présente dans Scalar et qu'**aucun** endpoint n'est inventé. Les sept autres lois pinnent la palette ccup (L2), l'absence d'env-gate (L3), l'isolation par-projet (L4) via le token partagé (L5), que rien n'écrit de vérité (L6), et que Pagefind indexe **chaque** page (L9). Les **6** fixtures (Godog-class, N2) épinglent le parcours : l'app émet bien son substrat de docs, Scalar rend chaque endpoint **sync** (createOrder/listOrders présents, archiveOrder async exclu, `SourceHash == apisurface.SourceHash`), Fumadocs rend les concepts du domaine (ccup + FR-défaut bilingue), Pagefind **indexe et trouve** (terme domaine → hit, hors-domaine → aucun hit), les docs sont une **projection jamais une vérité**, et une spec malformée est **refusée**. Que la doc *projette* l'app plutôt que de la *paraphraser* n'est pas une promesse — c'est une propriété prouvée.

- **Déterminisme-first (§6/§8) : projeter une doc, indexer, trouver sont des fonctions pures, donc du code.** DP30 n'invite **aucun** LLM — ni pour écrire une page, ni pour décrire un endpoint, ni pour classer une recherche. `EmittedDocs` est **TOTAL** : aucune horloge, aucun rng, aucun ordre de map, aucun chemin absolu, aucune I/O. `SearchIndex` est un **token-match** pur (pas de classement appris). L'adresse `DocsID` content-adresse le corps canonique via `CanonicalDocs`, si bien que « même Kernel ⇒ mêmes docs » est **une seule comparaison d'octets** — la loi `TestL7SameKernelSameDocs` le pin. Une doc d'app qui ferait *inventer* une page à un agent serait un **trou de déterminisme** (une doc qui diverge de l'app qu'elle décrit) — ici, le code projette, l'agent ne s'assoit jamais dans la boucle.

- **Réutiliser plutôt que réinventer (ADR 0007), sur DP15/16/17/18 + S90.** DP30 n'invente **ni** un moteur de fragments, **ni** une seconde source de la surface API. Pour la mécanique des fragments, il **calque** DP15/16/17/18 (role/profile, images émises, `depends_on`) et **réutilise** `datafragments.IsolationToken` (le token DP15) pour l'isolation par-projet. Pour la référence API, il **réutilise** S90 `apisurface` : la projection Scalar consomme `apisurface.PathOf` + le chemin `openapi.json` d'`apisurface.EmitOpenAPI`, et `SourceHash == apisurface.SourceHash(spec)` — la doc API **est** la surface S90, à la même adresse, jamais un second openapi forké. Et la **validation** n'est pas re-coinée : elle est **déléguée** à `apisurface.EmitOpenAPI`, dont le `BlockReason` est surfacé **verbatim** via `*DocsRefusal`. Il **ne duplique** rien : pas un second émetteur d'API à côté, mais **une projection** qui lit le Kernel + l'OpenAPI et les assemble en docs.

## Méta-méta

- **Les docs sont une PROJECTION, JAMAIS une vérité — et DISTINCTES des docs AIDOS (le mur, §2).** C'est la frontière fine que DP30 grave. `WritesTruth()` renvoie **`false`** sur **chaque** `ServiceFragment` **et** sur la `DocsProjection` ; **aucune** capability `docs:*` ne matche `IsTruthWriteCapability` ; `IsProjection = true`, `WroteKernel = false`. Projeter la doc d'une app n'écrit **rien** dans `kernel`, `mirrors` ou `fitness` (la fixture `DocsAreAProjectionNeverATruth` l'épingle) — et un spec malformé donne un refus typé, jamais un panic. Et il y a **deux** docs qu'il ne faut jamais confondre : les docs **d'AIDOS** (le *journal de build* sur `aidos.mintlify.app`, la page que vous lisez), et les docs **de l'app émise** (la doc *de votre produit*, gravée par DP30). DP30 ne touche **que** la seconde ; l'agent n'a aucun GRANT pour graver une vérité, et la seule porte vers le kernel reste idée → mirror → `/goal` → approbation humaine.

- **Une seule rangée « docs » DP14, cassée en 3 fragments — backend-only, le front intact.** La règle est nette : la palette mesurée (DP14) déclare déjà côté front (`substrate-palette.ts`) **une** rangée `docs` (Fumadocs + Scalar + Pagefind, en GO) ; DP30 fait, côté backend, ce qu'elle annonce — il la **casse** en ses **trois** fragments constituants (fumadocs:3400 / scalar:3500 / pagefind:3600), **sans aucun changement front en périmètre** (`SubstrateDocsFragments` ne touche pas à `substrate-palette.ts`). Aucun écran Workbench n'est ajouté (la tâche est scopée backend), mais les types de projection sont **JSON-taggés** — prêts pour un futur panneau `/v2` docs qui consommerait la `DocsProjection`. C'est l'anti-overwrite (§9) tenu : on **ajoute** un paquet, on **n'altère** rien du front ni des fragments DP15–18.

Un OpenQuestion non-bloquant subsiste, par-design (forward dep) : le miroir n'est **pas encore** persisté au schéma Postgres `mirrors` — exception bootstrap S06, où le test **EST** la preuve red→green, back-fillée au pas qui bâtit le schéma.
