## Implémentation

**Le modèle Go `back/runtime/honoemit/screendesign.go`** — le requirement de design, content-adressé, **below-the-line** (il étend la voie `ViewAdaptation`, jamais `MasterView` — un changement structurel passerait par /goal) :

- `ScreenCoord {Kind: section|field|action, Entity, Field, Control}` — la **coordonnée-requirement** qu'un élément DOM projette. Elle **normalise le drift d'attributs** vérifié dans les `_render.go` : `{data-aidos-view, data-aidos-screen, data-aidos-panel} → section`, `{data-aidos-col, data-aidos-field} → field`, `data-aidos-invoke → action`.
- `StyleToken {Property, Token}` d'un **catalogue FERMÉ** ADR 0010 (`bg/text/border/radius/pad/gap/align` + `size/weight/shadow/density/width/cols`), **fail-closed** : un hex ou une utilitaire Tailwind arbitraire est **refusé**.
- `ScreenOverride {Coord, Styles, Label}` et `ScreenDesign {ID, ChildTarget, ParentID, Overrides, Validated, By}` — `ID = records.Hash` du corps canonique, **append-only** (un override changé → un nouvel ID, jamais une mutation).

**Les quatre fonctions pures** : `EmitScreenDesign` (valide chaque token contre le catalogue + chaque coord contre la maître ; une coord absente est **refusée honnêtement** en nommant /goal) ; `ClassifyGesture(GestureInput) → Styling|Structural` (**TOTAL**, *structural-wins* — un geste qui touche à la structure ne peut pas se déguiser en style) ; `CapitaliseScreenDesign` (le **calque** de `CapitaliseViewAdaptation` → `compound.Compound`/`firewall.ViaIdea`, avec `WroteKernel()==false` épinglé par miroir — le mur) ; `ReproduceScreen` (folde les designs **validés** → `AdaptationOverride{Screen}` → `EmitWeb/Mobile/DesktopChildAdapted`, **byte-stable** ; override `nil` → **byte-identique au canonique**, l'anti-drift §9).

**Le bridge iframe ↔ lentille** : `aidos-bridge.embed.ts` (émis dans les trois enfants, **calque exact** de `aidos-expr.embed.ts`) scanne les `data-aidos-*`, fait le handshake `postMessage` (`ready`/`selected`/`mutated`/`edit-proposed`) et applique les **previews optimistes** (mutation de classes-token, **jamais la source**). `bridge-protocol.ts` = une **union discriminée fermée** dont le parseur **ne crash jamais** (message typé ou `null`).

**Le twin front `lib/v3/design/screen-design.ts`** : `composeScreenDesign` produit l'**EXACT** `records.Hash` de Go (un SHA-256 navigateur-sûr + une canonicalisation JSON byte-égale) ; `classifyGesture` et le catalogue fermé sont **verdict-pour-verdict** avec Go (prouvés par des hashes **dorés** capturés d'un `go test`) ; `aidos-bridge.embed.ts` est **byte-égal** au const Go. `layers-tree.ts:deriveLayersTree` dérive l'**arbre composes/fractal** (la maître → les 3 enfants → les sections → les champs/actions) ; la **détection de composants** = la **source kernel** de chaque nœud (entité S35, control→action S11), jamais une heuristique.

**Le chat IA gaté** : `designChatTurnAction` (calque `chatTurnAction`) — le LLM **propose** une phrase canonique de la grammaire fermée ; `rejudgeDesignProposal` est **l'autorité** (pure/totale/fail-closed) : il re-parse + re-juge la proposition via le catalogue + `composeScreenDesign` + `classifyGesture` → `styling` (un `ScreenDesign` draft) | `structural` (« capture l'idée : … » → /goal) | `refused` (hex/hors-catalogue, **jamais capturé**). IA éteinte, le texte brut suit le même chemin déterministe.

**Les branches** : `design-branches.ts` **délègue** au twin du DAG S24 (`seedDesignDag`/`foldCaptures`/`openDesignBranch`/`forkFromPoint`/`restoreCheckpoint`) — une branche de design = un nœud du DAG, un checkpoint = une phase stable ; la persistance est une projection below-the-line. **`DesignIframe`** charge l'app **LIVE** dès que `provisionStatusAction(slug)` la dit en ligne ; et le **déploiement par projet réapplique** les `ScreenDesign` validés (`EmitWebChildAdapted`) pour la **permanence** — la consigne survit au redéploiement.

## Méta

Le miroir n'est pas un test ajouté : c'est le **done-criterion**. Pour chaque pièce, une propriété ∀ : `EmitScreenDesign` **idempotent** (mêmes entrées, ordre indifférent → même ID) ; `ReproduceScreen` **byte-stable** sur les 3 enfants et **byte-identique au canonique** quand l'override est vide (l'anti-drift, le coût assumé de l'ADR — le web child gagne son **premier** point d'adaptation sans casser sa byte-identité) ; `ClassifyGesture` **total** + un `StyleToken` hors-catalogue **refusé** ; `CapitaliseScreenDesign.WroteKernel()==false` **toujours** (le mur épinglé) ; le twin TS **verdict-pour-verdict** avec Go (même ID, même nature, catalogue identique) ; le bridge **byte-égal** Go↔TS. Côté front, la **loi de couverture** (`lib/v3/coverage.test.ts`) couvre automatiquement la 9e lentille ; les e2e Playwright sont **hermétiques** (IA éteinte, twin déterministe) — la lentille, la capture, le mur structurel (un geste structurel → une idée `hasMirror=false`, jamais un `ScreenDesign`). Le rendu cross-origin live n'est pas testé en e2e : il est **validé à la main sur le déploiement** (les spans OTel et le rouge réapparu en sont la preuve).

## Méta-méta

Le Design Lab est l'illustration la plus nette de **determinism-first** (§6/§8) appliqué à une surface réputée « créative ». Onlook met un LLM/un éditeur **dans la boucle d'écriture du code** ; AIDOS l'en **sort** : le déterministe (le catalogue fermé, `composeScreenDesign`, `ReproduceScreen`) est **autoritaire**, le LLM est l'**exception gatée** confinée à proposer une phrase qu'on re-juge. C'est le **mur** (§2) tenu à la lettre — le studio est, *par construction*, incapable d'écrire une vérité : la seule porte vers le kernel reste `idée → miroir → /goal`. C'est **anti-overwrite** (§9) — on **étend** `AdaptationOverride`, on n'altère pas `MasterView` ; le web child gagne un override sans casser sa byte-identité. Et c'est le **cliquet** : chaque consigne est content-adressée, chaque branche un nœud du DAG (S24) — rien n'est jamais effacé, revenir en arrière ou bifurquer ne supprime aucune version. L'ADR 0071 grave la décision : implémenter Onlook **complètement** sans jamais le laisser écrire le code — parce que l'instrumentation `data-aidos-*` était déjà là, gratuite.
