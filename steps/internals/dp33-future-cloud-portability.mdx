## Implémentation

### Le paquet — `honoemit` (étendu, additif)

DP33 **étend** `back/runtime/honoemit/`, **strictement additif** (anti-overwrite §9 — aucun fichier existant n'est touché, aucun `gen/` n'est édité à la main). Il prouve la **portabilité future-cloud** : le **même** `StackManifest` se projette vers **deux** cibles de déploiement **sans** réécrire la déclaration (« une source → N projections », ADR 0043 amendé, EPIC G). `EmitPulumiStack` (le self-hosted prouvé), `connresolve.ResolveConnection` (DP07) et `scope.EnvFutureCloud` (DP06) sont **réutilisés intégralement** — **rien n'est forké**. C'est une tâche **backend-only** : aucun écran Workbench n'est ajouté (le front + la doc Mintlify sont des tâches séparées hors de ce périmètre).

Les deux fichiers DP33 (écrits mirror-first — l'impl **après** le miroir) :

- `back/runtime/honoemit/pulumi_stack_target.go` — l'impl.
- `back/runtime/honoemit/pulumi_stack_target_test.go` — le miroir, écrit **RED→VERT**.

### La dimension `Target` — un jeu fermé en ordre canonique

```go
type Target string

const (
	TargetSelfHosted  Target = "self_hosted"
	TargetFutureCloud Target = "future_cloud"
)

var targetSetOrder = []Target{TargetSelfHosted, TargetFutureCloud}

func Targets2() []Target  // une COPIE — jamais dérivée d'une map ; nommée Targets2 pour
                          // ne PAS collisionner avec honoemit.Targets() (cibles-de-FICHIER)
func IsTarget(t Target) bool

var ErrUnknownTarget = fmt.Errorf("honoemit: deployment target is outside the closed set …")
```

`Target` est un **set fermé** : `self_hosted` (l'émetteur Pulumi `@pulumi/docker`) et `future_cloud` (le provider managé). `targetSetOrder` est la **liste gravée** en **ordre canonique** ; `Targets2()` en renvoie une **copie** (jamais dérivée d'une itération de map — déterminisme §6). Le nom `Targets2` évite la collision avec l'énumération **orthogonale** `honoemit.Targets()` : ce sont **deux jeux fermés différents** — `Targets()` énumère des **kinds de fichier**, `Targets2()` des **cibles de déploiement**. Une cible **hors** du jeu est repliée dans un `BlockReason` (`ErrUnknownTarget`, la forme S13 réutilisée — jamais un nouveau code de prison), jamais devinée (l'honnêteté §8, comme un rôle inconnu).

### `EmitPulumiStackTarget` — l'émetteur dimensionné par cible

```go
func EmitPulumiStackTarget(project, env string, m StackManifest, target Target) ([]Artifact, *blockreason.BlockReason)
```

Le cœur du paquet. Il dispatche sur la cible :

- **`!IsTarget(target)`** ⇒ `block(ErrUnknownTarget)` — la cible inconnue est refusée d'emblée.
- **`target == TargetSelfHosted`** ⇒ `return EmitPulumiStack(project, env, m)` **verbatim** — le `@pulumi/docker` **prouvé en or** par demoshop-dev, **byte-identique** : la cible cloud est **purement additive** (anti-overwrite §9), elle ne touche **rien** de l'émetteur existant.
- **`target == TargetFutureCloud`** ⇒ la projection cloud du **même** manifest. Gardes fail-closed (`project`/`env` vides ⇒ `block(ErrNoProject/ErrNoEnv)` ; `validateManifest(m)` err ⇒ `block`), puis :

```go
stack := project + "-" + env
sourceHash, err := stackSourceHash(project, env, m) // calculé sur le MÊME triple — la source est LUE,
                                                     // jamais re-déclarée. Les bytes du programme cloud
                                                     // diffèrent, mais l'ADRESSE-CONTENU de la source
                                                     // est IDENTIQUE à la projection self-hosted.
program, err := emitFutureCloudProgram(stack, sourceHash, m)
dir := "gen/" + project + "/infra/"
// 3 artefacts, triés par Path :
//   Pulumi.yaml   (TargetPulumiScaffold)
//   index.ts      (TargetPulumiProgram)
//   package.json  (TargetPulumiScaffold)
```

### La projection cloud — services managés → `managed_url`, services applicatifs → `cloud.Service`

```go
var cloudManagedRoles = map[ServiceRole]bool{
	RoleDatastore: true, RoleBus: true, RoleCache: true, RolePooler: true, RoleWorkflow: true,
}
func isCloudManaged(role ServiceRole) bool { return cloudManagedRoles[role] }

func emitFutureCloudProgram(stack, sourceHash string, m StackManifest) ([]byte, error)
```

`cloudManagedRoles` est le **jeu fermé** des rôles **managés** dans `future_cloud` (**déclaré jamais appris**, §8). `emitFutureCloudProgram` rend le programme Pulumi/TS sur les `canonicalServices(m)` (ordre **canonique**), `import * as cloud from "@pulumi/cloud"` :

- **Services managés d'abord.** Chacun (`isCloudManaged`) passe par `resolveManaged(s, m.Network)` et devient `const <var> = { service, mode, url: process.env[<NAME>_MANAGED_URL] }` — une **référence** `managed_url` résolue **au boot** depuis le secret store (S91). Ce **n'est pas** un `docker.Container` : c'est un service **externe**, managé par le provider.
- **Services applicatifs ensuite.** Chacun (non managé) devient `const <var> = new cloud.Service(name, { image, name, port[, domain] })`. Le `RoleServer` porte en plus le `domain` (`<stack>.<stackDomainSuffix>`) — l'**endpoint HTTPS public** du provider. `program()` renvoie `{ resources, managed }`, et `export const url = "https://<domain>"`.

### `resolveManaged` — réutiliser le résolveur DP07

```go
func resolveManaged(s Service, net Network) (connresolve.Resolution, error) {
	svc := stackmanifest.Service{Name: s.Name, Role: stackmanifest.Role(s.Role), Image: s.Image, InternalPort: s.InternalPort}
	return connresolve.ResolveConnection(svc, scope.EnvFutureCloud)
}
```

DP33 **mappe** la `honoemit.Service` vers sa contrepartie `kernel/stackmanifest.Service` (même `role` string, même `name`) puis **réutilise** `connresolve.ResolveConnection` (DP07) dans `scope.EnvFutureCloud` (DP06). En `future_cloud` le binding est **Managed**, donc tout service managé résout en `managed_url`. Le résolveur DP07 est le **seul** propriétaire de cette règle (§8, déclaré jamais appris) ; `honoemit` ne la **ré-implémente** jamais.

### Les miroirs — RED-first (∀ + fixtures)

Écrits **D'ABORD** ; l'impl amenée au VERT ensuite. Six tests dans `pulumi_stack_target_test.go` :

1. `TestTarget_Closed` — le jeu de cibles est **fermé** `{self_hosted, future_cloud}`, une cible inconnue est **refusée**.
2. `TestTarget_SelfHostedIsByteStableWithEmitPulumiStack` (∀ rapid) — `TargetSelfHosted ≡ EmitPulumiStack` **byte-pour-byte** (la preuve additive).
3. `TestTarget_ByteIdenticalPerTarget` (∀ rapid, **PROPERTY 1**) — le **même** manifest produit les **deux** cibles déterministiquement, chacune **ré-émise byte-identique** sous **permutation** de l'ordre des services.
4. `TestTarget_FutureCloudManagedURL` (fixture, **PROPERTY 2**) — datastore managé → `DB_MANAGED_URL`, bus → `EVENTS_MANAGED_URL` ; les services managés ne sont **pas** des `docker.Container` dans le cloud.
5. `TestTarget_SourceInvariantAcrossTargets` (∀ rapid, **PROPERTY 3** capitale) — `ManifestHash(m)` **inchangé** avant/après les **deux** projections (la source jamais mutée) ; les deux cibles partagent **un** `SourceHash` sur `index.ts` mais **diffèrent en bytes de sortie**.
6. `TestTarget_FutureCloudMalformedRefused` (honnêteté) — cible inconnue / manifest sans `server` = `BlockReason` **typé**.

Soit **6 tests DP33**, **6 PASS** (`go test -run TestTarget -v`) ; les `TestStack_*`/`TestProp_Pulumi*` préexistants restent **verts/byte-stables**.

- **Backend-only** — aucun écran ajouté ; l'API (`Target`, `Targets2`, `IsTarget`, `EmitPulumiStackTarget`, `ErrUnknownTarget`) est prête pour un futur écran qui *choisirait* la cible — **un paramètre**, jamais une re-déclaration.

## Méta

- **Le miroir Go est l'épreuve « le même manifest se projette vers N cibles, déterministiquement, sans jamais toucher la source », ∀.** Le miroir fixture épingle le **parcours** : le jeu de cibles est **fermé** (`TestTarget_Closed`), un datastore managé donne `DB_MANAGED_URL` et un bus `EVENTS_MANAGED_URL` sans devenir un `docker.Container` (`TestTarget_FutureCloudManagedURL`), une cible inconnue ou un manifest sans `server` est **refusé** (`TestTarget_FutureCloudMalformedRefused`). Le miroir property (rapid, N1) mesure le cœur déterministe en trois lois, dont une **capitale** : `TestTarget_SourceInvariantAcrossTargets` épingle que `ManifestHash(m)` est **inchangé** avant/après les deux projections (la source n'est jamais mutée) et que les deux cibles partagent **un** `SourceHash` tout en différant en **bytes de sortie**. `TestTarget_ByteIdenticalPerTarget` pin la reproductibilité par cible sous permutation, et `TestTarget_SelfHostedIsByteStableWithEmitPulumiStack` pin que la cible self-hosted est **byte-pour-byte** l'émetteur prouvé. Que la **source** soit *lue* plutôt que *réécrite*, que le self-hosted soit *identique* plutôt que *forké*, n'est pas une promesse — c'est une propriété **prouvée**.

- **Déterminisme-first (§6/§8) : la projection est du code, jamais un LLM.** DP33 n'invite **aucun** LLM — ni pour choisir *comment* projeter vers le cloud, ni pour *résoudre* un `managed_url`, ni pour *décider* quel rôle est managé. La **résolution `managed_url`** est la **table** DP07 (`connresolve.ResolveConnection`), pas un agent qui « comprend » une connexion ; le mapping rôle→managé est une **appartenance close** (`cloudManagedRoles`, déclaré jamais appris). `EmitPulumiStackTarget` est une fonction **pure, totale**, byte-stable de `(project, env, Canonicalize(manifest), target)` — sans horloge, sans RNG, l'**ordre de service canonique** (`canonicalServices`). Si bien que « même entrée ⇒ mêmes artefacts » est une **seule comparaison** d'octets. Un émetteur qui ferait *deviner* à un agent la cible, le `managed_url` ou l'ordre des services serait un **trou de déterminisme** (un programme cloud qui change à chaque émission) — ici, le code projette, l'agent ne s'assoit jamais dans la boucle runtime.

- **Réutiliser plutôt que réinventer (ADR 0007, §9), sur `EmitPulumiStack` + DP07 + DP06.** DP33 n'invente **ni** un second émetteur, **ni** un second résolveur de connexion, **ni** un parseur de manifest. La **seule** logique propre à DP33 est la **dimension `Target`** + la **projection cloud** (l'ordre managés-puis-applicatifs, le domaine HTTPS sur le `server`). Pour le **self-hosted**, il **délègue verbatim** à `EmitPulumiStack` (le `@pulumi/docker` prouvé). Pour les **`managed_url`**, il **réutilise** `connresolve.ResolveConnection` (DP07) ; pour l'**environnement cloud**, `scope.EnvFutureCloud` (DP06) ; pour le **content-address**, `stackSourceHash` ; pour l'**ordre**, `canonicalServices` — tout le runtime `honoemit` existant. Il **ne forke** rien : pas un second émetteur ni un second résolveur à côté, mais **une dimension** ajoutée à un émetteur déjà éprouvé.

## Méta-méta

- **Une source au-dessus de la ligne, N projections en dessous — le mur (§2).** C'est la frontière que DP33 grave. Le `StackManifest` reste la source **unique au-dessus de la ligne** ; les **deux** cibles sont des **projections en dessous de la ligne**, **pures**, du **même** manifest. L'émetteur n'écrit **aucune** vérité — rien dans `kernel`/`mirrors`/`fitness` ; il **lit** la source et **émet** des bytes dans `gen/`. La cible est une **dimension** de la projection, **pas** une seconde source à maintenir : changer de cible, ce n'est **jamais** réécrire la déclaration. **Pas de Coolify**, pas de PaaS qui réinterprète l'app à sa façon : la portabilité est **par projection**, et la projection est un **code déterministe** que la source gouverne entièrement.

- **Projeter, ce n'est pas dupliquer (anti-overwrite §9) — le self-hosted reste byte-identique.** La discipline est nette. DP33 **ajoute** une cible cloud **sans** toucher au self-hosted : `TargetSelfHosted` **délègue verbatim** à `EmitPulumiStack`, et `TestTarget_SelfHostedIsByteStableWithEmitPulumiStack` le **prouve** byte-pour-byte. Les `TestStack_*`/`TestProp_Pulumi*` préexistants restent **verts** : on **ajoute** une dimension, on **n'altère** rien de l'émetteur prouvé. La **source-invariance** est l'autre face de la même discipline — projeter vers une cible **ne touche jamais** la source (`ManifestHash(m)` inchangé) : la portabilité **n'érode** ni l'existant ni la source.

- **DP33 clôt EPIC G et la piste DP — la portabilité est prouvée par construction.** C'est le **dernier tooth** de la piste DP. La loi de complétude veille : une projection sans miroir serait un **monstre** — DP33 ne vit que parce qu'il porte sa preuve vivante (6 tests, RED-first, l'impl écrite **après** le miroir). Avec lui, la promesse d'EPIC G — « une source → N projections » — n'est plus une intention mais une **propriété** : le `StackManifest` se projette vers le self-hosted **réel** (byte-identique à l'émetteur prouvé) **et** vers le future-cloud (managé, `managed_url`), **déterministiquement**, **sans** jamais réécrire la déclaration ni muter la source. La porte vers le kernel reste, comme toujours, idée → mirror → `/goal` → approbation humaine ; et le reste — le front qui *choisirait* la cible, la doc Mintlify — sont des tâches séparées, *tout se fait par écran*, une cible de plus restant un **paramètre**, jamais une re-déclaration.
