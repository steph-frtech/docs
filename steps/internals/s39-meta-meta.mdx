## Couche 1 — Implémentation

**Le runner pur.** `back/hooks/sessionstart/selftest/Run(h Harness, at string) → (SelfTestReport, *BlockReason)` est une **fonction pure** de `(harness, at)` — pas de `time.Now()` dedans, pas de RNG, pas de fuite d'ordre de map — donc `Run(h,t) == Run(h,t)`. Elle exécute les **trois injections de faute déterministes** :

1. **Chaque capteur** — pour chaque id de l'inventaire S07, `ProbeSensor` injecte la faute connue et asserte que le détecteur `fired`. Les `SensorProbe` sont triés (ordre stable).
2. **Le mur** — pour chaque schéma above-the-line (`kernel`, `mirrors`, `fitness`), `ProbeWall` tente une écriture de l'agent et asserte `refused`.
3. **La fitness** — `FitnessProbe` recalcule `records.Hash(records.Canonicalize(rows))` (réutilise **S02**, jamais forké) et compare à la baseline gravée.

Le verdict est **calculé** (jamais déclaré) : `green` ssi tous les capteurs `fired` ∧ toutes les écritures `refused` ∧ `fitness unchanged` ; sinon `red` + le `BlockReason` précis (`MUTED_SENSOR` → `WALL_BREACHED` → `FITNESS_MUTATED`, dans un ordre de précédence fixe pour le déterminisme).

**Le port `Harness`.** Les trois facultés sont injectées : les miroirs pilotent un **fake adapter in-process** (rollback propre, reproductible) ; le `PgHarness` de production **PROBE** le vrai mur S04 (une connexion pgx bas-privilège `aidos_agent` qui tente une écriture above-the-line dans une transaction annulée) et **lit** les vraies lignes `fitness` (SELECT seulement). On ne ré-implémente ni les capteurs (S07) ni le mur (S04) : on les **sonde**.

**Le hook.** `back/hooks/sessionstart` (binaire `harness-self-test`, `package main`) est câblé à la phase `SessionStart` (`hooks.yaml`). Sur échec d'une garantie il écrit le `BlockReason` JSON sur stdout et sort en non-zéro — la session est **bloquée**. **Fail closed** : si le harness ne peut pas être construit (pas de DB, pas de baseline épinglée), il bloque — une garantie non prouvable n'est pas un laissez-passer (KRD §82). La baseline n'est **jamais devinée** (`SELF_TEST_FITNESS_BASELINE`, sinon une OpenQuestion).

**La persistance.** Migration Atlas **expand-only** `runtime.self_test_runs` (append-only) : `at`, `verdict CHECK(green|red)`, `sensors_fired/total`, `wall_refused`, `fitness_baseline_hash`, `fitness_current_hash`, `fitness_unchanged`, `block_reason jsonb`. **GRANT** : l'agent a **SELECT seulement** sur `fitness.*` et sur le ledger ; seul le rôle writer `aidos` insère les lignes de run. Elle n'altère jamais une table, un GRANT, ni la posture read-only de `fitness` antérieurs.

**La forme BlockReason.** Les trois codes (`MUTED_SENSOR` / `WALL_BREACHED` / `FITNESS_MUTATED`) réutilisent la **forme S13** `blockreason.BlockReason` mais sont déclarés **localement** (le précédent des hooks : chacun déclare ses codes localement ; étendre l'enum FERMÉ de S13 en place exigerait un ChangeSet + SemanticDiff — ADR 0029).

**L'écran.** `/meta` (`front/web/app/meta`) rejoue le **jumeau TS pur** de `Run` (`lib/meta.ts`, couvert par fast-check) sur un **scénario de harness choisi** et rend les trois garanties en vert/rouge + le résultat d'injection par capteur + la **baseline de fitness en LECTURE SEULE** (aucun contrôle éditable) + l'historique append-only. Le verdict est **rendu, pas re-calculé** côté serveur.

## Couche 2 — Méta (les miroirs)

- **Fixture (N2)** `selftest_fixture_test.go` (matérialisée de `tests/runtime/harness_self_test.fixture.md`) : harness sain ⇒ green (LE critère done) ; capteur muet ⇒ red + `MUTED_SENSOR` ; mur percé ⇒ `refused == false` + red + `WALL_BREACHED` ; fitness modifiée ⇒ `unchanged == false` + red + `FITNESS_MUTATED` ; le self-test n'écrit jamais la fitness (octet-identique) ; harness malformé (inventaire vide) ⇒ BlockReason, jamais un panic.
- **Propriété (∀, rapid)** `selftest_property_test.go` : déterminisme (`Run(h,t)==Run(h,t)`) ; tout-vert ⇒ green ; tout capteur muet ⇒ red ; toute écriture above-the-line acceptée ⇒ red ; fitness ≠ baseline ⇒ red ; read-only sur la fitness ; pas de panic / pas de capteur inventé sur entrée malformée.
- **Testcontainers** `selftest_ledger_roundtrip_test.go` : vrai Postgres + les baselines S02/S04/S07/S39 ; round-trip du ledger via le rôle writer ; **preuve de GRANT** — l'agent est refusé en INSERT/UPDATE/DELETE sur le ledger (SELECT seulement) ; le **mur tient** end-to-end (`PgHarness.ProbeWall` refusé sur kernel · mirrors · fitness) ; un mur percé (agent gagne INSERT sur kernel) vire au rouge ; la contrainte CHECK rejette un troisième verdict.
- **Jumeau TS** `lib/meta.test.ts` (fast-check 9/9) + **e2e** `tests/e2e/meta.spec.ts` (playwright-bdd, 5/5) — LE critère done à l'écran.

## Couche 3 — Méta-méta (qui surveille le surveillant)

Cette étape **est** le méta-méta — le miroir des miroirs. Sa propre signification est l'**injection de faute** : elle redden délibérément chaque garde-fou et asserte qu'il se déclenche. C'est pourquoi §5 (hook-honesty : *un hook qui ne se déclenche jamais est mort*) est satisfait **sans** régression séparée « est-ce que le self-test détecte ? » : le plancher est la **mutation déterministe**, pas un juge-LLM. **Il n'y a pas de niveau 4** : qui gouverne le méta-méta ? L'humain + la réalité, point (KRD §70). La fitness est lue, jamais écrite — le contrôleur ne peut pas toucher ce qu'il contrôle ; c'est la garantie qui empêche le Goodhart ultime (une boucle qui se réécrit sa propre note).

## Dépendances réutilisées (jamais ré-implémentées)

- **S02** `records.Canonicalize` / `records.Hash` — le hash de contenu de la fitness.
- **S04** le mur + les GRANTs + le jeu de schémas protégés (`kernel`, `mirrors`, `fitness`) — **sondés**.
- **S07** l'inventaire des capteurs + la surface de détection « fired » — **sondés**.
- **S13** la forme `BlockReason` (code/severity/explanation/how_to_fix).
