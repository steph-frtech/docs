## Implémentation

**Le module Go jetable `spike/stackmanifest`** (module autonome `aidos.spike/stackmanifest`, jamais importé par `back/`) :

- `model.go` — `StackManifest{AppName, Services[]{Name, Role, Image, InternalPort, Profile}, Volumes[]{Name, DeviceVar}, Network{Name, External}, ConnectorScopes[]}` ; `Fixture()` épingle la sonde : app `alphaspike`, un `server` (port interne 3571) + un `datastore` (postgres), un volume bind dont le device est une **référence de variable** (`APP_DATA_PATH` — jamais un chemin en dur), le réseau `traefik_default` externe, un scope `postgres:read-only`.
- `emit.go` — `Emit(m)` **pur** : copies triées (`sort.Slice` sur les noms), lignes pliées par `strings.Join(b, "\n")`, fins de ligne `\n`, zéro horloge/RNG/ordre de map. Le compose émis reproduit les conventions `/data/dockers` : `container_name: ${APP_NAME}-<svc>`, `env_file: .env`, **aucun port publié**, labels Traefik (routeur HTTPS websecure/tls + middleware redirect HTTP→HTTPS) pour le rôle `server`, volume nommé `driver_opts:{type:none, device:${APP_DATA_PATH}, o:bind}`, `restart: unless-stopped`, healthcheck. L'en-tête embarque `source_hash` — le lien projection→source.
- `hash.go` — `Canonicalize(m)` (champ-explicite, trié, `\n`) ; `SourceHash`/`OutputHash` = sha256 hex ; `DriftDetected(recordedHash, bytes)` = comparaison de hash ; `TemplateCanDetectDrift()` = **false par construction** (le template ne possède aucun hash enregistré) — l'asymétrie EST la mesure décisive.
- `roundtrip.go` — `ParseCompose` (parseur de lignes pur, apparié à l'émetteur jetable) recouvre la topologie compose-visible (services avec rôle/image/port/profile, volumes, réseau) ; `TopologyEqual` la compare au manifest. Les `ConnectorScopes` sont exclus **par design** (ils ne vivent pas dans le compose — affaire du mur/agentlayer, EPIC E).
- `measure.go` — `Measure()` : 100 ré-émissions (byte-identity), round-trip, hand-edit d'un octet → `DriftDetectedOnSource=true` / `DriftDetectedOnTmpl=false`, coût proxy `EmittedBytes` ; `scoreForms()` : les 3 formes (record-kind / scope-dimension / below-the-line-projection) × 4 critères **DÉCLARÉS** (corps, content-address, mur, append-only), `Fit` = comptage ; `Decide()` = `byteIdentical ∧ roundTrip ∧ driftSource ∧ ¬driftTemplate` → **GO**, forme retenue `record-kind` (4/4). `Verdict` est entièrement comparable (`[3]FormScore`, aucune slice) — le miroir épingle `Decide() == Decide()`.
- `harvest.go` — `Harvest(v)` → `HarvestRecord` DRAFT content-adressé (`RecordHash` = sha256 du record canonique, champ exclu) : `Proposes="entity"`, `HasMirror=false`, `HasVersion=false` (il **propose**, jamais ne gèle), 4 OpenQuestions (forme proxy vs migration réelle, round-trip AST YAML réel en DP03, sous-ensemble de conventions, capture réelle via `idea_capture`).
- `measure_test.go` — le **miroir écrit d'abord** (rouge : `undefined: Emit…`, puis vert) : 7 lois — byte-identique ×100, conventions exactes (et **zéro** `ports:`, zéro host/secret en dur), round-trip, asymétrie de dérive, source-hash stable ET sensible, verdict reproductible + record content-adressé, fit = comptage déterministe.
- `cmd/verdict` — imprime la mesure + le record JSON. Mesuré : `source_hash 04b2c7abec6a…729dfb`, `output_hash 665a85273e71…adefa065`, `record_hash c1bcdd9d4a82…a77102`, **GO**.

**Le jumeau TS `front/web/lib/stack-spike.ts`** — port pur de la sonde (fixture, canonicalize, emit, hash sha256 via `node:crypto` lazy, parseur, verdict, harvest). Le miroir vitest `lib/stack-spike.test.ts` (6 tests) épingle la **parité octet-pour-octet avec le Go autoritatif** : les constantes `GO_SOURCE_HASH`/`GO_OUTPUT_HASH` sont les hash MESURÉS par `go run ./cmd/verdict` — si le jumeau diverge de l'émetteur Go d'un seul octet, le miroir rougit. Suite front entière : 2060/2060.

**La route `/stack-spike`** — server component (`decide()` + `harvest()` au rendu), panneau client `StackSpikePanel` : badge verdict (`data-verdict`), les 4 mesures, table des 3 formes, octets comparés (compose émis + les deux hash), record /harvest + OpenQuestions. **Un seul contrôle** : « ré-émettre » (`reEmitAction`, server action) re-exécute `decide()` et compare `output_hash` au hash initial (`data-equal="true"`) — il **re-mesure, n'écrit rien**. Thème ADR 0010 (tokens, jamais de zinc en dur), bilingue ADR 0011 (`stackSpike` dans `messages/{fr,en}.json`, FR d'abord), entrée nav dans `WorkbenchHeader`. E2e Playwright `tests/e2e/stack-spike.spec.ts` **4/4** (verdict GO rendu + octets comparés, le contrôle s'exécute et prouve la byte-identité depuis l'écran, record DRAFT, 3 formes comptées) ; les e2e V3 restent **16/16**.

**L'ADR 0064** grave le verdict mesuré (tableau des mesures, formes, conséquences pour DP02/DP03, OpenQuestions du record).

## Méta

- **Le SPIKE-gate est la forme honnête du doute.** La roadmap aurait pu déclarer « le StackManifest est une bonne idée » — DP01 la force à le **mesurer** d'abord, avec un no-go qui tue la roadmap entière. Le spike est jetable (T0, `/spike` seulement), mais sa **mesure** ne l'est pas : elle est harvestée comme record content-adressé.
- **Le verdict est une conjonction de hash, pas un jugement.** Quatre booléens mesurés (`byteIdentical`, `roundTripOK`, `driftSource`, `¬driftTemplate`) et un comptage 4/4 — aucun LLM dans le chemin du verdict. C'est `determinism-first` appliqué à la décision elle-même.
- **L'asymétrie de dérive est l'argument entier.** Byte-identité et round-trip, un bon template les a presque ; ce qu'il ne peut PAS avoir, c'est un hash enregistré qui rend tout hand-edit détectable. La mesure isole exactement le delta de valeur de la source — c'est elle qui justifie DP02.
- **Mirror-first même à T0 :** le test fixture a été écrit avant le code et a rougi (`undefined: Emit`) — le ratchet est OFF, pas la méthode.

## Méta-méta

- **Une porte qui peut tuer sa propre roadmap est la seule porte crédible.** DP01/DP10/DP14/DP19 encodent un principe rare : le plan accepte d'être falsifié par sa première étape. Si le verdict no-go n'avait aucune conséquence réelle (arrêt + ADR d'abandon), la « mesure » serait du théâtre.
- **La parité jumeau-épinglée-par-hash généralise.** Pin les hash du moteur autoritatif (Go) comme constantes dans le miroir du jumeau (TS) : toute divergence d'un octet entre les deux plans rougit un test unitaire — un Pact de facto entre back et front, au prix de deux constantes.
- **Le spike modélise la capture sans l'exécuter** (OQ-DP01-4) : le record /harvest a la FORME exacte d'une Idea (`proposes`, provenance, `has_mirror=false`) sans toucher au schéma `ideas` — la frontière entre « prouver le payoff » et « écrire la vérité » reste nette même dans du code jetable.

## Place dans le cliquet KRD

DP01 n'ajoute **aucune dent au cliquet** (ratchet OFF — c'est sa définition) : il ajoute la **preuve mesurée** que la prochaine dent (DP02, le record kind `stack_manifest`) mérite d'exister. Le mur est intact (zéro écriture kernel/mirrors/fitness, zone `/spike` seulement), le vert antérieur est intact (vitest 2060/2060, e2e v3 16/16), et le verdict GO + ses OpenQuestions sont la phase stable que DP02 consomme.
