S29 livre le **moteur de goal** §56–§59 comme une capacité du **Runtime** (`back/runtime/goal`) : la **seule porte** d'une idée vers la vérité — `idea → mirror → /goal`. Le moteur **ouvre** le goal et **calcule** son stop ; il **réutilise** S02 (le content-hash), S20 (l'enveloppe ChangeSet DRAFT), S22 (la dérivation du set rouge) et S13 (le `BlockReason`) **sans** les redéfinir. La **règle** — « un goal ouvre un ChangeSet DRAFT + ≥1 miroir rouge ; il se ferme seulement quand c'est calculé-fait » — est celle de l'humain (KRD §57/§63①/§8). Aucune vérité écrite par l'agent (le mur) ; l'agent ne note **jamais** sa propre copie.

## Implémentation

<Note>La couche **Implémentation** est complétée au vert (CLAUDE.md §6) — code réel, fichiers. Les couches **Méta** et **Méta-méta** ci-dessous sont écrites dès le grill.</Note>

- **`back/runtime/goal/goal.go`** — le moteur pur. **`OpenGoal(OpenInput) → (Goal, *BlockReason)`** : (1) rejette une idée **sans** `MirrorDelta` avec **`IDEA_WITHOUT_MIRROR`** (aucun ChangeSet ouvert — un vœu/monstre) ; (2) ouvre un **ChangeSet DRAFT** via **`changeset.Open`** (S20) portant le `spec_delta` + le `mirror_delta` **atomiquement** ; (3) **dérive** le set rouge via **`redwave.Impact`** (S22) — les miroirs que le bump fait rougir, jamais réimplémentés (l'`Edge` du goal est un **alias** de `redwave.Edge`) ; (4) rejette un set **vide** avec **`NO_RED_SET`** (une idée déjà verte n'est pas un goal). En succès, rend un `Goal` **OPEN**, content-addressé. **`IsClosed(goal, StopInput) → bool`** implémente §63 ① : `redSet → vert ∧ priorGreen == intact ∧ mutation ≥ mutationFloor ∧ len(monsters) == 0`. **`StopInput` n'a délibérément aucun champ de confiance** — le moteur ne lit jamais l'auto-évaluation de l'agent ; un verdict de sensor **manquant** est traité comme **rouge** (anti-passthrough). **`CloseBlockReason`** rend `GOAL_STILL_RED` quand `IsClosed` est faux. **`ComputeID`** = `records.Hash(records.Canonicalize(body))` (S02 réutilisé — le statut, métadonnée de cycle de vie, est **exclu** de l'adresse). Tout est **pur et total** — sans horloge, sans rng, sans I/O, ne panique jamais (la propriété l'épingle).
- **`back/runtime/blockreason/blockreason.go`** — **trois codes ajoutés** à l'enum clos (extension additive, `change_type: refine`, jamais une suppression ; via ChangeSet + SemanticDiff) : **`IDEA_WITHOUT_MIRROR`** (`how_to_fix : draft_mirror_for_idea`), **`NO_RED_SET`** (rien à fermer), **`GOAL_STILL_RED`** (la fermeture refusée — `close_red_mirrors` / `restore_prior_green` / `raise_mutation_or_remove_monster`). Chaque code garde un `how_to_fix` non vide (jamais une prison).
- **`back/hooks/goal-check/main.go`** — le hook **`Stop:goal-check`** (la règle non-contournable, CLAUDE.md §5), un **frère** du gate de complétude (`back/hooks/stop`) : il **AJOUTE** un garde-fou, n'en retire aucun (un Stop n'est admis que si **tous** les gates Stop l'autorisent). Il **DÉLÈGUE** à `goal.CloseBlockReason` — il ne réimplémente pas le stop (determinism-first). Il lit les verdicts vivants depuis un événement **injecté** (`sensors`, `prior_green`, `mutation`, `mutation_floor`, `monsters`) — il ne **plonge pas** dans `kernel`/`mirrors`/`fitness` (le mur). **Fail-closed** : un événement non décodable est refusé (exit 2, `GOAL_STILL_RED`) — un Stop non vérifiable ne passe pas (KRD §82).
- **`back/migrations/ideas_goal_baseline.sql`** — migration **expand-only / append-only** ajoutant `ideas.goal` : `id text PK` (= hash du corps), `body jsonb` (`{idea_ref, changeset_ref, red_set, status, budgets}` — le **set rouge vit DANS le body**, refs version-pinnées, **pas** des clés étrangères, pour rester inspectable après bouger les heads), `idea_ref`, `changeset_ref`, `status CHECK(OPEN|CLOSED)`, `created_at`, `closed_at NULL` (+ une contrainte `closed_at` cohérent avec le statut, et `body->>status = status`). **GRANT : l'agent a `SELECT` seulement** ; `INSERT/UPDATE/DELETE` sont **révoqués**. Seul le rôle `aidos` insère un goal et l'estampille `CLOSED` ; la transition `DRAFT→APPLIED` reste la porte de commit de S20. Le mur des schémas de vérité est **réaffirmé** (kernel/mirrors SELECT-only).
- **Skill `.claude/skills/goal/SKILL.md`** (CLAUDE.md §5 — geste rejouable) : `/goal`, la forme harnais de §57 — prendre une idée → `OpenGoal` → conduire red→green outside-in → fermer **seulement** quand `Stop:goal-check` passe. Elle porte les **Honesty rules** (jamais inventer un target/business-rule ; une idée sans miroir est un monstre ; l'incertitude devient une OpenQuestion) et le stop non-gameable. Frère de `open-goal` (la forme revue/approbation humaine).

## Méta

Le comportement de S29 est prouvé par **deux miroirs** (chacun de la bonne nature) + le test d'injection de faute du hook + le jumeau front, tous rouges avant le code (le rouge **est** le `/goal`). L'ouverture, la dérivation du set rouge et le stop à quatre conditions sont des **fonctions pures déterministes**, jamais un « agent qui décide si c'est fini » (CLAUDE.md §6/§8 — determinism-first) : le code gagne, et le hook **délègue** à `IsClosed`. C'est exactement la circularité §57/§58 que S29 ferme — l'agent n'écrit **jamais** un test-vérité qu'il satisferait ensuite ; il ne fournit **aucune** confiance au moteur.

<Steps>
  <Step title="Fixture du moteur (le miroir N2, state → command → events, authority: above)">
    `back/runtime/goal/goal_fixture_test.go` : **le critère done** — `TestOpeningAGoalCreatesADraftChangeSetAndNonEmptyRedSet` (depuis `idea-order-discount`, un ChangeSet **DRAFT** portant `spec_delta` + `mirror_delta`, un set rouge **non vide** `{ Order.discount.fixture }`, statut **OPEN**, `idea_ref`/`changeset_ref` pinnés) ; `TestAnIdeaWithNoMirrorIsRejected` (⇒ `IDEA_WITHOUT_MIRROR`, `how_to_fix` ⊇ `draft_mirror_for_idea`, aucun goal/changeset) ; `TestAnAlreadyGreenIdeaHasNoGoal` (le miroir pinné au head vivant ⇒ set vide ⇒ `NO_RED_SET`) ; `TestTheGoalClosesOnlyWhenRedSetGreenAndPriorGreenIntact` (rouge ⇒ stop false ; rouge→vert ∧ vert antérieur intact ∧ mut ≥ seuil ∧ aucun monstre ⇒ stop true) ; `TestAnyFaultKeepsTheGoalOpen` (vert antérieur cassé / rouge survivant / mutation basse / monstre ⇒ stop false) ; `TestRecordedGoalIDIsContentHashOfBody` (`goal.id == Hash(Canonicalize(body))`, S02).
  </Step>
  <Step title="Propriété rapid (le miroir N1, ∀, below the line — la reproducibilité)">
    `back/runtime/goal/goal_property_test.go` — sur **toute** entrée : `TestOpenGoalAlwaysOpensDraftWithNonEmptyRedSet` (DRAFT jamais APPLIED, set rouge non vide, OPEN) ; `TestOpenGoalRejectsMirrorlessIdea` (`IDEA_WITHOUT_MIRROR`, aucun goal) ; `TestOpenGoalRejectsAlreadyGreenIdea` (`NO_RED_SET`) ; `TestIsClosedIsDeterministic` (même entrée ⇒ même verdict — et **aucune** entrée de confiance à tirer) ; `TestAnyFaultMeansNotClosed` (tout rouge survivant OU vert cassé OU mutation < seuil OU monstre ⇒ `IsClosed == false`) ; `TestClosedImpliesAllFourHold` (un goal fermé ⇒ **les quatre** conditions tiennent) ; `TestOpenGoalAndIsClosedNeverPanic` (une idée/goal malformée rend un BlockReason/verdict, jamais un panic).
  </Step>
  <Step title="Hook fault-injection + jumeau front + e2e">
    `back/hooks/goal-check/main_test.go` **casse ce qu'il surveille** : `TestHookAllowsCloseWhenAllFourConditionsHold` (les quatre tiennent ⇒ exit 0) ; `TestHookBlocksCloseOnSurvivingRed`, `…OnBrokenPriorGreen`, `…OnLowMutation`, `…OnMonster`, `…OnMissingSensorVerdict` (chacun ⇒ exit 2, `GOAL_STILL_RED`, `how_to_fix` non vide) ; `TestHookFailsClosedOnGarbage` (événement illisible ⇒ deny). Le jumeau front `front/web/lib/goal.test.ts` (fast-check, 5/5) épingle les **mêmes** invariants (`isClosed` ssi les quatre tiennent, tout fault ⇒ pas fermé, déterminisme, verdict manquant = rouge) sur `lib/goal.ts`, et l'e2e Playwright `tests/e2e/goal.spec.ts` (4/4) prouve le critère done **à l'écran** : ouvrir un goal montre le badge **DRAFT** + **≥1 miroir rouge** + statut OPEN ; le stop lit **NON satisfait** tant qu'un miroir est rouge, et **satisfait** seulement quand le set rouge est vert et le vert antérieur intact ; le **burndown des budgets** est rendu.
  </Step>
</Steps>

La **complétude** tient : la couche goal (la table `ideas.goal`, la vérité de promotion) a son miroir vivant (fixture + propriété rapid + test d'injection de faute du hook + jumeau front + e2e) ; pas de monstre (aucune branche `OpenGoal`/`IsClosed` sans scénario ; aucun goal fermé pendant qu'un miroir est rouge ou qu'un vert antérieur est cassé ; aucune idée promue sans miroir).

## Méta-méta

Pourquoi un **stop calculé** plutôt qu'un agent qui dit « j'ai fini » ? Parce qu'un agent qui **note sa propre copie** est la faille structurelle de tout `/goal` du marché (Codex CLI, Claude Code) : le stop par défaut est **faible**, gameable — l'agent peut toujours **se convaincre** d'avoir réussi. KRD §57 répond par un stop dont **aucune** entrée n'est la confiance de l'agent : `set rouge → vert ∧ vert antérieur intact ∧ mutation ≥ seuil ∧ aucun monstre`. Les quatre sont **observables** et **déterministes** — le set rouge vient de la vague de rouge (S22), le vert antérieur des sensors, la mutation du mutation-runner, les monstres de la loi de complétude. Le moteur **n'a même pas** de champ pour lire « combien l'agent est sûr ». C'est l'incarnation de la distinction §58 : le test-comme-goal (humain, au-dessus du mur) est ce que l'agent **doit atteindre** ; le test-comme-moyen (agent, sous le mur) est ce qu'il **écrit pour y arriver** — mais **jamais** un test-vérité qu'il **satisferait** ensuite (la circularité). Et l'**ouverture** est gardée symétriquement : une idée n'entre que par son **miroir** (sinon un vœu), et seulement si elle **fait rougir** quelque chose (sinon rien à fermer). Enfin, que `ideas.goal` donne à l'agent **`SELECT` seulement** n'est pas une précaution de plus : c'est le stop non-gameable **gravé dans le schéma** — l'agent ne peut **structurellement pas** écrire une ligne `CLOSED`, le gel est le rôle `aidos` via la porte de commit (S20). Le Juge, ici aussi, est **déterministe** : la même idée, les mêmes verdicts vivants — toujours le même OPEN/CLOSED, calculé, jamais déclaré.
