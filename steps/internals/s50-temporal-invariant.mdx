## En une phrase

S50 pose le **substrat d'invariant temporel** : un package Go pur `back/kernel/temporal` (l'AST + `Validate` avec la **règle de l'horloge obligatoire** + `Evaluate` avec la **bande de tolérance unilatérale**), une migration qui **élargit** le `CHECK cert_language` du `mirror_record` (S06) à `statechart`/`tla+` et **ajoute** un fragment `temporal jsonb` **nullable** sur `kernel.truth` (le pattern expand-only de S14), des miroirs `fixture` (statechart) + `rapid` + roundtrip Testcontainers, un twin front pur + `fast-check`, et le panneau `/temporal-invariants` action-capable avec son e2e Playwright — sans lire **aucune horloge réelle**.

## Couche 1 — Implémentation

**Le package Go (`back/kernel/temporal/temporal.go`).** L'AST : `TemporalInvariant{property, antecedent, consequent, relation, bound, clock, tolerance, mirror}`. `Clock` est un set fermé de trois (`system`, `external`, `logical`) ; `MirrorForm` un set fermé de trois (`statechart`, `tla+`, `uppaal`) ; `Relation` ferme sur `within`. `Bound` et `Tolerance` sont des **chaînes de durée Go** (`"5m"`, `"10s"`) parsées par `time.ParseDuration` — jamais un entier nu.

- **`Validate(inv)`** — `property`/`antecedent`/`consequent` non vides ; `relation` reconnue ; `bound` parsable et non négatif ; la **règle portante** : `clock` **déclarée** (vide ⇒ `ErrMissingClock`, distinct de `ErrUnknownClock` pour hors-enum, comme S14 distingue missing/unknown) ; `tolerance` parsable et non négative (zéro autorisé) ; `mirror` dans le trois-set ; une horloge `logical` avec une tolérance murale non nulle refusée (`OQ-S50-logical-tolerance`).
- **`Evaluate(inv, obs) → TemporalVerdict`** — pur, total (`held | violated`), ne panique jamais. Pour un délai `within` : antécédent absent ⇒ `held` (l'implication est vacuement vraie) ; conséquent absent ⇒ `violated` (le délai n'est jamais atteint) ; conséquent **avant** l'antécédent ⇒ `violated` (§49.3 ordre des événements) ; `elapsed ≤ bound + tolerance` ⇒ `held` ; `elapsed > bound + tolerance` ⇒ `violated` + `BlockReason{TEMPORAL_INVARIANT_VIOLATED, how_to_fix:[confirm_within_5m_or_compensate, …]}`. La bande est appliquée **exactement une fois**, **unilatérale** (ADR 0034). **Aucun `time.Now()`** : le datum `elapsed` est dans l'`Observation`.
- **`SerializeBody(inv)`** — un body `{"kind":"truth","temporal_invariant":…}` qui round-trip via `records.NewRecord` (S02) : `id == version == Hash(Canonicalize(body))`.

**La migration (`back/migrations/kernel_temporal_invariant_baseline.sql`).** Expand-only, append-only, **deux moves**. **Move 1 (miroir)** : le `CHECK mirror_record_cert_language_check` (S06) est **élargi** pour admettre `statechart` + `tla+` (élargir un CHECK = expand-only, aucune ligne existante ne le viole) ; `uppaal` n'est **pas** ajouté à cet enum — aucune ligne ne l'utilise encore, et un membre d'enum mort est un monstre (§5 hook-honesty appliqué aux enums). **Move 2 (kernel)** : une colonne `temporal jsonb` **nullable** sur `kernel.truth` (les lignes existantes intactes, **pas de backfill, pas de flip NOT NULL** — le pattern S14 à l'identique), avec un `CHECK` épinglant `clock ∈ {system, external, logical}` et `mirror ∈ {statechart, tla+, uppaal}` **quand le fragment est présent**. `temporal` n'est **pas** un membre de `truth_kind` (§13.4 ne le liste pas — on n'invente pas d'enum). **GRANTs inchangés** : l'agent reste **SELECT-only** sur `kernel.truth` et `mirrors.mirror_record` (le mur).

**Les miroirs (RED → GREEN).** `temporal_fixture_test.go` (le statechart `checkout-confirm-within-5m` : `4m58s` held, `5m04s` held *dans la tolérance*, `5m20s` violated/`TEMPORAL_INVARIANT_VIOLATED` avec `confirm_within_5m_or_compensate`, hors-ordre violated, horloge manquante rejetée) ; `temporal_property_test.go` (rapid : `Evaluate` total + déterministe — le miroir de reproductibilité —, la bande appliquée exactement une fois sur `[0, 10m]`, la borne inclusive, les gardes `Validate`) ; `migration_roundtrip_test.go` (Testcontainers : roundtrip du fragment, le CHECK clock/mirror rejette le hors-enum, le CHECK cert_language élargi accepte `statechart`/`tla+` mais rejette `uml`, le mur SELECT-only). Source matérialisée : `tests/kernel/checkout-confirm-within-5m_temporal_invariant.fixture.md`.

**Le twin front + l'UI.** `front/web/lib/temporal.ts` (projection pure, mêmes lois, durées en secondes) + `lib/temporal.test.ts` (fast-check, 9/9). Le panneau `/temporal-invariants` (`components/TemporalInvariantPanel.tsx` + `app/temporal-invariants/page.tsx`) : carte invariant (property/clock/tolerance/mirror/bound/relation), marqueur de bande verte `5m ± 10s`, table d'évaluation calculée par l'évaluateur pur (la ligne `5m20s` rouge, le tag *dans la tolérance* sur `5m04s`), contrôle propose→ChangeSet (stub, le mur) + contrôle ré-évaluer (lecture seule). Bilingue (`messages/{fr,en}.json`, 34 clés/langue), thémé (tokens ADR 0010), nav câblé. E2e `tests/e2e/temporal-invariants.spec.ts` (7 scénarios).

## Couche 2 — Méta

**Pourquoi ces choix.** §49.3 décrit la TemporalInvariant en YAML minimal et laisse `tolerance: ...` **opaque** ; plusieurs branches sont tranchées ici et tracées (ADR 0034, OpenQuestions). (1) La **bande est unilatérale** pour `within` : on viole une échéance en étant en retard, jamais en avance — la lecture conservatrice d'un délai. (2) `temporal` **n'est pas** un `truth_kind` (§13.4 ne le liste pas) — la nature temporelle rit dans le **fragment** + la `cert_language`, jamais un membre forgé. (3) Le `mirror_record` n'est élargi qu'aux **deux formes qu'une ligne utilisera** (`statechart`, `tla+`) — `uppaal` attendra une vraie ligne temps-réel dur (§778). (4) Une horloge `logical` rejette une tolérance murale (un compteur de pas n'a pas de secondes). Le `clock` **nomme** l'horloge que le runtime échantillonnera plus tard ; cette étape n'échantillonne **rien**. Le code `TEMPORAL_INVARIANT_VIOLATED` est **local** (comme `sagas.CodeSagaInvariantViolated`), réutilisant la **forme** S13 du BlockReason — pas un membre de l'enum fermé `runtime/blockreason.Code`.

**Pas de hook, MCP, skill, codegen ni model-checker.** L'évaluation temporelle est une **fonction de décision** que le flux runtime/sensor appellera, pas une règle de mur (un hook maintenant serait mort — §5) ; aucune capacité backend nouvelle exposée (le sensor qui échantillonne une horloge est plus tard) ; déclarer un invariant temporel n'est pas encore un geste répétable distinct ; rien à émettre depuis un AST temporel ; le runner TLA+/UPPAAL est une cap T2 rare (§778), hors slot.

## Couche 3 — Méta-méta

**Déterminisme-first.** Tout ce que S50 introduit **est** une fonction pure et **doit** être du code, jamais un agent ni une horloge réelle : parser la durée, comparer l'`elapsed` *passé en entrée* à la borne élargie, décider `held|violated`, vérifier l'ordre des événements, refuser une horloge manquante, hasher le body. `Validate`/`Evaluate` sont **autoritaires** (même `(invariant, observation)` ⇒ même verdict). **Aucun `time.Now()`, aucun sleep, aucune horloge réelle, aucun LLM** dans la boucle. Le **miroir de reproductibilité** (rapid en Go, fast-check au front : même entrée ⇒ même sortie) épingle cette propriété — un agent ou une horloge qui « déciderait » à la place de l'évaluateur pur serait un **écart de déterminisme** qui bloque l'étape, comme une capacité headless ou un monstre. C'est précisément pourquoi l'`elapsed` est passé en entrée : un test temporel qui lirait `time.Now()` serait non reproductible et flakerait.

**Anti-écrasement et le mur.** Un nouveau contrat (les shapes AST, les enums `clock`/`mirror`/`relation`, la sémantique de la bande de tolérance, le code BlockReason) **ajouté**, aucun antérieur réécrit. La migration est **expand-only** : fragment `temporal` nullable + `CHECK` élargi — aucune ligne existante touchée, aucun GRANT modifié. Toute évolution d'un contrat amont (S02, S06 `mirror_record`/cert_language, S14 truth-typing, S15 `TimeWindow` — gardé **distinct**, jamais repurposé en horloge, le BlockReason, les GRANTs) passerait par ChangeSet + SemanticDiff. L'agent n'a **aucun GRANT d'écriture** sur `kernel.truth` ni `mirrors.mirror_record` — la vérité ne s'écrit que via le rôle CLI `aidos`, sur ChangeSet approuvé.
