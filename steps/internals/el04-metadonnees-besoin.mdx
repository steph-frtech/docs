## Implémentation

La certification des quatre métadonnées dans **`back/runtime/besoin/metadata.go`** (au-dessus du record EL03) :

- **Types** — `Metadata{TruthKind(truthtyping.TruthKind), Verifiability(truthtyping.VerifiabilityLevel), Scope(scope.TruthScope), Authority(*authority.AuthorityGraph), Granted([]authority.Role)}` : chaque champ est une **valeur typée de son package d'origine**, jamais du texte libre. `MetaGap{Code, Field, Explanation, HowToFix[]}` (chaque manque nomme la porte). `MetadataVerdict{Complete, Gaps[], Routing(truthtyping.Zone), RouteToSpike}`.
- **La fonction autoritaire** — `CertifyMetadata(node, m) → MetadataVerdict` est une **fonction pure totale**. Ordre déterministe des contrôles : (1) `truth_kind` — absent ⇒ `missing-truth-kind`, hors-enum ⇒ `unknown-truth-kind` (via `truthtyping.IsKnownKind`) ; (2) `verifiability` — absent/hors-enum ⇒ gap, sinon **réutilise `truthtyping.Classify`** pour la zone (donc `RouteToSpike` quand `unverifiable`/`delayed`) ; (3) `scope` — un nœud actif (resolved/drafting) sans scope et non-global est rejeté par **`scope.Validate`** ⇒ `missing-scope`, un scope mal formé ⇒ `malformed-scope` ; (4) `authority` — seulement pour les kinds qui l'exigent (`regulatory`), via **`authority.Validate` + `authority.Decide`** : nil ou `DecisionBlocked` (le done-case `MISSING_AUTHORITY_APPROVAL`) ⇒ gap. `Complete` = aucun gap.
- **Une seule source d'enum** — `TruthKindIsCoherent(k)` renvoie `truthtyping.IsKnownKind(k) == authority.IsKnownTruthKind(authority.TruthKind(k))` : comme `authority` **délègue** sa connaissance à `truthtyping`, les deux ne divergent jamais. Aucun second registre.

**Miroir fixture-table** (`metadata_property_test.go`) — écrit ROUGE d'abord, puis VERT :
- une **table de fixtures** mutant UNE métadonnée à la fois sur une baseline complète (behavioral + deterministic + global) : `missing/unknown truth_kind`, `missing/unknown verifiability`, `missing/malformed scope`, `regulatory sans autorité`, `regulatory avec autorité mais sans approbation accordée` → tous **incomplets** avec leur code ; `regulatory + legal accordé` → **complet** ;
- `TestCertifyMetadata_UnverifiableRoutesToSpike` : un nœud `unverifiable` route `/spike`, **et la zone égale** celle de `truthtyping.Classify` (pas de fork) ; un nœud `deterministic` route la zone kernel ;
- `TestTruthKind_SingleEnumSource` (rapid) : sur les sept kinds + des chaînes hors-enum, `truthtyping` et `authority` **s'accordent toujours** ;
- `TestCertifyMetadata_Reproducible` (rapid) : même nœud + mêmes métadonnées → **verdict identique** (Complete, codes de gaps dans le même ordre, routing) — la reproductibilité (déterminisme §6/§8).

**Jumeau TypeScript** `front/web/lib/besoin-metadata.ts` — miroir de `CertifyMetadata` : `certifyMetadata(status, m)` applique le **même** ordre de contrôles et la **même** table `ALLOWED_MODE` (la règle déclarée §13.5), reproduisant le verdict du moteur Go. Son **miroir de reproductibilité** `besoin-metadata.test.ts` (vitest + fast-check) pin **14 cas** (la fixture-table, le routage /spike, la source unique d'enum, la reproductibilité).

**Route Workbench** `/compound-besoin-metadata` **action-capable** (`BesoinMetadataPanel.tsx`) : l'utilisateur choisit le statut + les quatre métadonnées, « Certifier les métadonnées » EXÉCUTE `certifyMetadata` et affiche le verdict (complet / les gaps, un par métadonnée) + le chip de routage `/spike` ; « Prouver la source unique d'enum » exécute `truthKindIsCoherent`. Thémé (ADR 0010), bilingue FR-default (ADR 0011). **e2e Playwright** `tests/e2e/besoin-metadata.spec.ts` (4/4 vert contre le serveur live).

## Méta

EL04 est une démonstration de **`determinism-first`** appliqué à la **classification** : le verdict « ce nœud est-il assez qualifié pour avancer ? » est calculé par trois fonctions pures du kernel, jamais par un jugement LLM. La skill `classify-truth` **orchestre le dialogue** (elle aide l'humain à choisir un `truth_kind`), mais le **juge est le code** — `CertifyMetadata` re-vérifie ce que l'humain a déclaré contre les enums clos et les guards des trois packages. C'est la règle §8 (« le juge est déterministe ») appliquée au besoin.

La **réutilisation des trois packages** — plutôt qu'une reclassification maison — est ce qui garantit la **cohérence inter-niveaux** : le `truth_kind` que le besoin porte au-dessus du mur est exactement celui que `truthtyping.Classify` consultera plus bas (à l'admission, EL16 → app-builder), et exactement celui sur lequel `authority.Decide` keye. La **délégation** `authority → truthtyping` (vérifiée par la property single-enum-source) interdit la dérive : il ne peut pas exister un `truth_kind` « connu d'authority mais inconnu de truthtyping ». Le routage `/spike` passe par la **porte légale** (`idea_capture` → `idea_grill` → `idea_spike`), jamais une capture directe en `spiking` — EL04 respecte le mur jusque dans son routage consultatif.

## Méta-méta

Au niveau méta-méta, EL04 ajoute une **garde** sans en retirer aucune (le méta-loop §5) : un nœud de besoin ne peut plus avancer « vide de qualificateurs ». La complétude est ici **co-prouvée sur deux plans** — le miroir Go autoritaire et le jumeau TS — et la **source unique d'enum** est elle-même une forme de complétude méta : la capacité « typer une vérité candidate » n'existe qu'**une fois** dans le système (truthtyping), tout le reste y délègue, donc il n'y a pas de monstre « deux enums divergents ». Aucune capacité headless (ui-completeness) : chaque opération de certification (les quatre métadonnées, le routage, la preuve d'enum unique) a un contrôle exécutable depuis l'écran, prouvé par Playwright. Les dépendances en aval — la persistance JSONB des métadonnées (EL15, schéma `besoin`), l'orchestration complète de `classify-truth` dans l'interview (EL13) — sont des **OpenQuestions déclarées** (exception bootstrap §6), non bloquantes : la certification est complète et prouvée seule, sa persistance se back-fille à son étape.
