## Implémentation

### Le package Go `back/kernel/entities`

- **`entities.go`** — l'AST source :
  - `ScalarType` : le **jeu fermé** `string | int | decimal | bool | timestamptz` (les types ubiquitaires, déclarés, jamais inventés). `IsKnownType` lit la table de mapping.
  - `Attribute { Name, Type, Required, Identifier?, Multivalued? }` — **ordonné** : sa position dans `Attributes[]` est **sémantique** (l'ordre struct/champ/colonne).
  - `Entity { Name, Attributes[] }` — la source ; `ID(e) = records.Hash(records.Canonicalize(Body(e)))` (**S02 réutilisé**, jamais reforké). `Body` passe par `records.Canonicalize` (tri des clés d'objet) mais **préserve l'ordre du tableau** d'attributs.
  - `Validate` : pas de nom ⇒ refus ; pas d'attribut ⇒ refus ; type hors jeu ⇒ `ErrUnknownType` ; **plus d'un** `identifier` ⇒ refus (une seule PK).
- **`emit.go`** — les trois emitters **purs / totaux / déterministes** :
  - `typeMap : ScalarType → {ddl, gos, ts}` (`string→TEXT/string/string`, `decimal→NUMERIC/pgtype.Numeric/string`, `int→BIGINT/int64/number`, `bool→BOOLEAN/bool/boolean`, `timestamptz→TIMESTAMPTZ/pgtype.Timestamptz/string`).
  - `EmitGo` : la struct, un champ par attribut **en ordre source**, `go/format.Source` la rend gofmt-clean par construction (fonction pure ⇒ byte-stable). `pgtype` importé seulement si utilisé.
  - `EmitTS` : `export type Order = { … }`, un attribut **non requis** rend un champ **optionnel** (`discount?`).
  - `EmitDDL` : `CREATE TABLE "order" ( … )`, `required → NOT NULL`, l'`identifier → PRIMARY KEY`, identifiants quotés (un mot réservé comme `order` reste valide).
  - Un type inconnu / un AST malformé ⇒ `blockUnknownType(cause)` qui retourne un `blockreason.BlockReason` (**S13 réutilisé**, `how_to_fix` non vide — pas de prison), **sans** émettre d'octets.
- **`example.go`** — l'entité canonique `Order` : `id:int identifier required, customer:string required, total:decimal required, discount:decimal, placed_at:timestamptz required`.
- **`cmd/materialize`** — matérialise les trois projections sous `back/gen/order-entity/` (Go + DDL) et `front/web/gen/order-entity/` (TS), chacune avec le header protégé `// CODE GENERATED BY AIDOS — DO NOT EDIT. source: <hash>`.

### La persistance — `back/migrations/kernel_entity_baseline.sql`

Migration **expand-only / append-only** ajoutant `kernel.entity` (`id TEXT PK`, `body JSONB`, `version TEXT`, `superseded_by TEXT NULL`, `created_at`), avec la **CHECK `version = id`** (content-addressed en base). **GRANT** : `aidos_agent` reçoit **SELECT only** (le mur — une entité est une vérité humaine au-dessus de la ligne) ; seul le rôle `aidos` insère via un ChangeSet approuvé. Elle n'altère ni ne supprime aucune table/GRANT antérieure.

### Le jumeau front — `front/web/lib/entity-source.ts`

Le **jumeau déterministe** du package Go : même AST, mêmes trois emitters, **byte-identique** au Go (vérifié sur les trois artefacts `Order` — `EmitGo`/`EmitTS`/`EmitDDL` ; `entityId(Order) = 5f39ec78…`, identique au hash Go). Distinct de `lib/emitters.ts` (S34) : celui-ci **trie** les champs et met `NOT NULL` partout ; **ce** jumeau **préserve l'ordre** et est **required-aware**. L'écran `/entity-map` rend exactement ce que les emitters calculent — pas de réimplémentation, pas de LLM.

## Méta

Les **miroirs** qui prouvent S35 (le miroir requis d'une `entity` est **schema-validation**, KRD §27 : `entity ─mirrors→ schema-validation`) :

- **Fixture schema-validation** (`entities_fixture_test.go`, N2 `state → command → events`) — **les critères « done »** :
  - `Order` émet une struct Go + un type TS + du DDL (chaque attribut en ordre source, type mappé ; `id → PRIMARY KEY` ; `required → NOT NULL`/non-optionnel ; `discount → NULLABLE`/optionnel) ;
  - les trois projections **s'accordent** sur le même jeu d'attributs (jamais double-typé) ;
  - l'`id` enregistré == `Hash(Canonicalize(body))` ;
  - un attribut de type inconnu est **Bloqué** (`UNKNOWN_ATTRIBUTE_TYPE`), rien n'est émis.
- **Propriété `rapid`** (`entities_property_test.go`, ∀, sous la ligne) — déterminisme, totalité, no add/drop/rename, ordre préservé, `required ⇔ NOT NULL ⇔ TS non-optionnel`, exactement **une** PK sur l'`identifier`, stabilité du content-address (un réordonnancement ⇒ un nouvel `id`).
- **Round-trip Testcontainers** (`migration_roundtrip_test.go`) — sur un vrai Postgres : l'AST round-trip en JSONB content-addressed (ordre préservé), la CHECK refuse une ligne non content-addressed, et le rôle `aidos_agent` est **SELECT-only** (INSERT/UPDATE/DELETE ⇒ `permission denied` — **le mur prouvé de bout en bout**).
- **Jumeau front `fast-check`** (`lib/entity-source.test.ts`, 8/8) — les mêmes invariants côté TS, ancrés sur l'exemple `Order` (hash == celui du Go).
- **Playwright** (`tests/e2e/entity-map.spec.ts`, 4/4) — `/entity-map` montre la source `Order` + les trois projections (`type Order struct`, `export type Order`, `CREATE TABLE "order"` avec PK sur `id` et `discount` nullable), RE-EMIT byte-identique, MOVE THE HEAD → stale.

## Méta-méta

- **Le cliquet (KRD ratchet).** L'entité est une **SOURCE N3** (contrats / entités). S35 ne réinvente pas la roue : il **réutilise** S02 (`Canonicalize`/`Hash`, le substrat content-addressed) et S13 (`BlockReason`) comme contrats importés, jamais édités. Il **n'invente aucune** vérité — l'agent n'écrit pas une truth-test ; les fixtures/propriétés sont des **means-tests** vers le rouge humain (« une entité émet une struct Go + un type TS + du DDL, fidèles à une source »).
- **Le mur (CLAUDE.md §2).** `kernel.entity` est au-dessus de la ligne : `GRANT SELECT` seulement à l'agent ; toute écriture de vérité passe par un ChangeSet (rôle `aidos`). `back/gen/**` est **généré, jamais édité à la main** (§4/§9) — pour changer une projection, on change la source et on ré-émet.
- **La complétude.** `kernel.entity` (la source) a son miroir vivant (fixture schema-validation + propriété) ; pas de **monstre** (pas de source sans miroir, pas de projection qui drift, pas de `gen/` édité à la main).
- **Determinism-first (§6).** Les trois emitters sont des **fonctions pures** — aucun LLM, aucune horloge, aucun hasard. Le code est **autoritatif** ; le jumeau TS le **reproduit** byte-pour-byte ; la propriété `rapid` + `fast-check` est la **reproductibilité** prouvée.
- **ADR.** Aucun ADR nouveau : S35 reste **dans** les slots gelés (N3 source → Go+TS+DDL, sqlc/pgx, Atlas, fixture/rapid). Le jeu scalaire fermé est l'unique **OpenQuestion** de périmètre (les types ubiquitaires du domaine `Order`) — élargi additivement si un besoin réel émerge, jamais deviné.

## Limites connues

`Order` seule (pas de relations / FK / `composes`) ; pas de couches `api`/`operation`/`policy`/`control`/`action` ; pas d'expansion behavior-macro ; pas de Pact cross-cell ; DDL émis mais **non appliqué** (Atlas applique plus tard) ; pas de MCP `emit`/`codegen` (les emitters sont une lib pure — OpenQuestion si un op callable devient nécessaire).
