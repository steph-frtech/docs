S26 livre la **décision de curation** (KRD §44.4) et la **sélection quality-diversity** (KRD §62, algorithme ②) : deux fonctions **pures** — `Curate(nodes, policy, now) → []CurationDecision` et `Elites(variants) → map[nicheKey]Variant` — plus la route Workbench **/archive-curation**. La **règle** — « le DAG est une mémoire vivante, pas une décharge ; trois bandes déclarées keep/compress/tombstone ; l'histoire critique n'est jamais détruite ; une variante n'entre dans une niche que si son miroir est vert ; une élite par niche à la fitness ancrée » — est celle de l'humain (KRD §44.4 / §62 / §123). Aucune vérité écrite par l'agent (le mur) ; `Curate`/`Elites` sont des **décideurs en lecture seule**.

## Implémentation

<Note>La couche **Implémentation** est complétée au vert (CLAUDE.md §6) — code réel, fichiers. Les couches **Méta** et **Méta-méta** ci-dessous sont écrites dès le grill.</Note>

- **`back/archive/curation/curation.go`** — le cœur **pur** de la curation (aucune I/O, aucune horloge, aucun rng, **aucune écriture**). Les types : **`Node`** (`id`, `kind`, `flags []Flag`, `createdAt`) = les métadonnées que les étapes précédentes portent ; **`Policy`** = l'**ArchiveCurationPolicy AST**, les trois bandes comme ensembles de prédicats déclarés (`DefaultPolicy()` les matérialise **exactement** comme §44.4 les déclare — `version = "krd-44.4"`) ; **`Verdict`** = l'ensemble **fermé** `keep | compress | tombstone` ; **`CurationDecision`** (`nodeId`, `verdict`, `reason`). **`Curate(nodes, policy, now)`** classe **chaque** nœud par la **précédence de sûreté** `tombstone > keep > compress`, keep par défaut conservateur : un flag tombstone (unsafe/obsolète) gagne sur keep ; sinon un flag keep (pareto_elite/incident_related/high_novelty) ou le kind `stable_phase` ⇒ keep ; sinon un `duplicate_behavior`, ou un `failed` plus vieux que **30 jours** (`now - created_at`, `now` est un **paramètre**) ⇒ compress ; sinon **keep**. **Chaque** id d'entrée apparaît **exactement une fois** en sortie — tombstone/compress ne **suppriment jamais** un nœud (append-only). `Hashed()` estampille l'**adresse de contenu** S01/S02 (`records.NewRecord(KindPhase, body)`), jamais un hash forké. Total, déterministe, **ne panique jamais**.
- **`back/archive/qd/qd.go`** — le cœur **pur** de la sélection QD. **`Variant`** (`id`, `niche`, `mirror`, `fitness`) ; **`MirrorStatus`** = `green | red` (le Juge déterministe). **`Niche(variant) → nicheKey`** rend le descripteur **déclaré** que la variante porte (pas un embedding appris). **`Elites(variants) → map[nicheKey]Variant`** : une variante est candidate **uniquement si son miroir est vert** (un rouge est ignoré, **quelle que soit** sa fitness — l'ancre anti-Goodhart) ; parmi les verts d'une niche, l'élite est celui à la **fitness ancrée maximale** (égalités tranchées par le plus petit id, déterministe) ; **une** élite par niche (MAP-Elites — un front de Pareto de cellules, jamais un champion global) ; une niche dont les seuls candidats sont rouges n'a **pas** d'élite (cellule vide). Ne **invente** jamais une niche ou une fitness — chaque élite est une variante d'entrée rendue verbatim.
- **`back/migrations/dag_curation_qd_baseline.sql`** — la migration **expand-only / append-only**, **additive** : `dag.curation_decision` (`id` = hash de contenu S01/S02 en PK, `node_id`, `verdict` avec `CHECK (verdict IN ('keep','compress','tombstone'))`, `reason`, `policy_version`, `decided_at`) et `dag.niche_elite` (`niche_key`, `elite_node_id`, `fitness jsonb`, `recorded_at`, PK `(niche_key, recorded_at)` — une **nouvelle** élite est une **nouvelle ligne**, jamais un `UPDATE`). Un tombstone/compress est une **ligne de décision**, jamais un `DELETE`/`DROP` sur un nœud du DAG. Les tables S02 `dag.phase` et S23 `dag.stable_phase` sont **intactes** (aucun ALTER).
- **Le mur (CLAUDE.md §2)** : `dag` est un schéma de vérité **au-dessus de la ligne de flottaison**. L'agent reçoit **SELECT seulement** sur les deux tables (il lit le registre + la grille pour /archive-curation) ; `INSERT/UPDATE/DELETE/TRUNCATE` lui sont **refusés**. Seul le rôle writer `aidos` `INSERT` (la seule porte), via un ChangeSet approuvé (S20). La suite Testcontainers (`back/archive/curation/migration_roundtrip_test.go`) **prouve** sur un vrai Postgres : le `CHECK` du verdict refuse un `purge` ; l'agent peut `SELECT` mais son `INSERT`/`DELETE` est refusé ; `dag.niche_elite` est append-only (deux élites pour la même niche = deux lignes) ; les tables antérieures sont intactes.
- **Pas de nouveau MCP, hook, Skill, ni verbe CLI** (CLAUDE.md §5, choix explicite) : le mur garde déjà `dag.*` ; enregistrer une décision/élite passe par le MCP changeset S20 + le rôle writer `aidos` ; le geste `/evolve` qui **génère** des variantes est une dent ultérieure. Un nouvel artefact AJOUTE un garde-fou, jamais ne le retire.

## Méta

Le comportement de S26 est prouvé par **deux miroirs par paquet** (chacun de la bonne nature) plus le jumeau front, tous rouges avant le code (le rouge **est** le `/goal`). Les décisions sont des **algorithmes déterministes**, jamais un « agent qui décide quoi garder » ni un « LLM qui note une variante dans une niche » (CLAUDE.md §6/§8 — determinism-first) : le code gagne, le Juge est le miroir.

<Steps>
  <Step title="Fixtures de curation + QD (les miroirs canoniques, N2, authority: above)">
    `back/archive/curation/curation_fixture_test.go` (`reflects=archive.curation.Curate`) — `state` = des nœuds + la policy + un `now` passé · `command` = `Curate` · `events` = les verdicts : une **branche unsafe ⇒ tombstone** et le nœud est **toujours présent** (*LE critère done* — append-only) ; un **stable_phase + un pareto_elite ⇒ keep** ; un **failed > 30j ⇒ compress** (toujours présent) ; un failed < 30j ⇒ pas encore compressé ; **tombstone gagne sur keep** (un élite unsafe est quand même tombstone) ; l'**id de la décision == Hash(Canonicalize(body))** (S01/S02 réutilisé). `back/archive/qd/qd_fixture_test.go` (`reflects=archive.qd.Elites`) — une **variante à miroir vert ⇒ promue** comme l'unique élite de sa niche (*le critère done QD*) ; une variante à **miroir rouge** de **fitness plus haute ⇒ NON promue** (*l'ancre anti-Goodhart* — le Juge est le miroir, jamais le score) ; un **champion à fitness ancrée plus haute remplace l'élite** ; un vert bat un rouge de fitness plus haute ; **une élite par niche distincte** (diversité, pas un champion global).
  </Step>
  <Step title="Propriétés rapid (les invariants ∀, N1, authority: below)">
    `back/archive/curation/curation_property_test.go` — sur **tout** `(nodes, policy, now)` : **déterministe + total** (`now` passé, jamais lu de l'horloge ; verdict dans l'ensemble fermé) ; **tout nœud unsafe/obsolète ⇒ tombstone** ; **tout nœud keep-band (et pas unsafe/obsolète) ⇒ keep** ; **aucun nœud n'est jamais supprimé** (chaque id apparaît exactement une fois) ; **content-addressed** (`Hashed` rend une vraie adresse S02) ; **jamais de panique** (flags nil, created_at zéro). `back/archive/qd/qd_property_test.go` — **déterministe** ; **pas de vert ⇒ pas d'élite** (toute élite est verte ; une niche aux seuls rouges n'a pas d'élite) ; **une élite par niche à la fitness ancrée max** ; **n'invente jamais** une niche/fitness (toute élite trace à une variante d'entrée) ; **jamais de panique**.
  </Step>
  <Step title="Jumeau front fast-check + e2e (l'invariant côté Workbench)">
    `front/web/lib/archive-curation.test.ts` épingle les **mêmes** invariants côté Workbench (curation : déterminisme, any-unsafe⇒tombstone, keep-band⇒keep, aucun-nœud-supprimé ; QD : déterminisme, no-green⇒no-élite, une-élite-par-niche-à-fitness-max) sur les jumeaux `lib/archive-curation.ts`, plus les critères done sur les exemples canoniques — donc l'écran /archive-curation décide exactement comme les Go `Curate`/`Elites`. Un e2e Playwright (`tests/e2e/archive-curation.spec.ts`) prouve le critère done **visible à l'écran** : la branche unsafe rend **TOMBSTONE** tout en **restant listée** (pas disparue), un stable_phase/élite rend **KEEP**, un failed > 30j rend **COMPRESS**, la variante à miroir vert **remplit** sa cellule de niche, la niche aux seuls candidats rouges **reste vide**.
  </Step>
</Steps>

La **complétude** tient : `dag.curation_decision` + `dag.niche_elite` (la vérité curation/QD) ont leur miroir vivant (fixture + propriété + roundtrip migration Testcontainers + jumeau front + e2e) ; pas de monstre (aucune vérité sans miroir, aucun miroir orphelin, aucun nœud détruit en silence, aucune variante promue sur un miroir rouge).

## Méta-méta

Pourquoi **classer** plutôt que **supprimer**, et pourquoi un **miroir vert** comme unique porte d'entrée d'une niche ? Parce que les deux répondent au même danger : la **perte irréversible** et le **mensonge optimisé**. Une archive qui supprime peut jeter le **stepping stone** qui aurait semé le prochain saut — la valeur d'un ancêtre n'est pas son score courant, c'est sa **fécondité future** (KRD §62) ; donc on ne détruit jamais, on **classe** (un tombstone est un **marquage** réversible, pas un effacement). Et la quality-diversity n'a de sens que si l'on garde **la diversité** — **une élite par niche** (un front de Pareto de cellules), pas un seul champion global qui écraserait toute exploration. La pierre angulaire — **pas de promotion sans miroir vert** — est l'application directe de « le Juge est déterministe » (§8) : si l'on laissait un **LLM noter sa propre copie**, ou la **CellVitality** (diagnostique, §66.2) servir de fitness de promotion, on optimiserait le **score** et pas la **vérité** (Goodhart). Le miroir, lui, ne se laisse pas berner : une variante rouge n'entre **jamais**, **quelle que soit** sa fitness. Enfin, que la curation et la QD soient des **fonctions pures** sur `(nodes, policy, now)` et `(variants)` — `now` **passé**, jamais lu de l'horloge ; les bandes **déclarées**, jamais apprises ; la fitness **consommée**, jamais inventée — c'est ce qui rend la mémoire de l'OS **rejouable** : la même archive rend toujours la même curation, hier comme demain.
