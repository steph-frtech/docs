## En une phrase

S53 livre le **projet** : le concept Kernel de **premier rang** qui **scope toute vérité**. Avant S53, AIDOS était **un** graphe global indivis — aucune notion de « à qui appartient cette vérité ». Désormais chaque vérité appartient à **un projet**, et deux projets sont **disjoints** : ils ne se lisent jamais l'un l'autre.

## Le problème que ça résout

Vous voulez construire **votre** application avec AIDOS. Un autre utilisateur veut construire **la sienne**. Le truth-store (le Postgres où vivent les vérités) est **singleton** : sans frontière, vos deux apps se télescoperaient dans le même graphe. Le projet est cette frontière. C'est le **prérequis de tout le reste** : multi-tenant, identité, passerelle, modeleur, boucle-build, déploiement — tout se scope au projet.

## Ce que vous obtenez

Une route Workbench **`/projets`** où vous :

- **Créez** un projet : un *slug* (l'identifiant stable, unique chez vous), un *nom*, un *propriétaire*. Le projet reçoit une **empreinte** (son adresse de contenu) et un **nœud racine de DAG** isolé.
- **Archivez / restaurez / supprimez (en doux)** un projet — son cycle de vie est `actif → archivé → supprimé`, **toujours append-only** : rien n'est jamais détruit physiquement (la suppression dure GDPR viendra en S116).

## Les garanties

- **Unicité par propriétaire.** Deux propriétaires peuvent avoir un projet « boutique » ; un même propriétaire ne le peut pas. Le slug est votre clé humaine, unique chez vous.
- **Disjonction.** Le projet A et le projet B ne partagent **aucune** ligne. Le *scoping* — « ne me montre que les vérités de ce projet » — est une **fonction pure** : même entrée, même sortie, jamais une lecture croisée.
- **Adressage par contenu.** L'id d'un projet **est** l'empreinte de son contenu (réutilise le schéma S02). Créer deux fois le même projet est idempotent ; changer son cycle de vie produit une nouvelle empreinte (rien n'est écrasé).
- **Le mur tient.** Un projet est écrit **sous** le mur (le schéma `projects` n'est pas `kernel`/`mirrors`/`fitness`), via le chemin store — comme le magasin de contenu. Aucune vérité n'est écrite depuis l'écran.
