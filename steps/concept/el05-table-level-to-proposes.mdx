## En une phrase

EL05 déclare la table **`LevelToProposes(level) → ProposesKind | NoEmit`** : la **jointure honnête** entre les 9 niveaux de la grammaire du `BesoinGraph` et le **closed set existant** `ideas.ProposesKinds()`, sans jamais inventer un kind ni aliaser silencieusement un niveau.

## Le problème que ça résout

EL02 a fixé la grammaire (9 `Level` : 7 rungs SOURCE + les bandes `invariant`/`policy`). À la projection (EL16), chaque nœud `resolved` **dont le rung mappe** sort comme **Idea** via la porte `idea-intake`. Or une `Idea` porte un champ `Proposes` dont le closed set est **exactement** `control | policy | operation | action | entity | product` — **PAS** `journey`, **PAS** `view`, **PAS** `invariant`.

Il faut donc une **jointure** entre 9 niveaux et 6 kinds. Le piège anti-Goodhart : un **cast silencieux** (`journey → product`, `view → control`) qui ferait croire que tout rung émet une Idea — alors que `journey`/`view`/`invariant` n'ont **aucune** cible `Proposes` légale.

## Les idées-clés

<Field name="Self-map : la seule émission légale" type="control/action/operation/entity/product · policy">
  Les 5 rungs dont le **nom EST** un `ProposesKind` se mappent vers **eux-mêmes** (`entity → entity`, jamais `entity → control`). La bande `policy` se mappe vers `policy` (qui existe dans le closed set). C'est la **seule** émission permise : un niveau ne peut jamais aliaser le kind d'un **autre** niveau.
</Field>

<Field name="NoEmit : journey, view, invariant" type="ils seedent les ancres, n'émettent rien">
  `journey` et `view` n'ont **aucun** kind homonyme dans `ideas.ProposesKinds()` → ils sont **NoEmit** : ils **seedent** les `anchors_above[]` des rungs qui, eux, mappent — jamais un cast `journey → product`. La bande `invariant` est aussi NoEmit : son miroir est une **property (N1)**, pas un kind d'Idea ; elle contraint **latéralement**.
</Field>

<Field name="Aucun alias silencieux" type="journey→product interdit, view→view* impossible">
  Une property prouve qu'un niveau sans kind homonyme **doit** être NoEmit (jamais aliasé). `journey → product` est interdit ; `view → view*` est impossible (il n'existe aucun kind `view`). Un mapping vers un kind **hors** `ideas.ProposesKinds()` est une **erreur dure** — jamais une devinette LLM.
</Field>

<Field name="Table close = fonction pure" type="déterminisme §6/§8">
  La table est un **map déclaré, clos, total** dont le domaine est exactement `AllLevels()`. Même niveau → même mapping (property de reproductibilité). Ce n'est jamais un « choix de convenance » d'un LLM : c'est du code qui fait autorité.
</Field>

## Ce que ça change (et ne change pas)

EL05 ne franchit **jamais** le mur : la table décide **seulement** la cible `Proposes` — elle **n'émet aucune Idea** (c'est EL16 qui le fait, via la porte légale `idea-intake`) et n'écrit **aucune** vérité. Les nœuds `NoEmit` apparaîtront dans les `anchors_above[]` (EL08/EL17) : ils **contraignent sans émettre**, et le compteur d'Ideas (EL19) les **exclut**. Chaque non-mapping est tranché par l'**ADR 0041**, jamais un footnote.
