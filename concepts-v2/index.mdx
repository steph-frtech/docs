## En une phrase

**Les concepts** est la carte de lecture de la Workbench V2 : une page par notion, rangées dans l'**ordre du schéma** — l'ordre où elles apparaissent à l'écran, de l'**idée** brute jusqu'à l'**app émise et déployée**.

## Pourquoi cette section existe

La Workbench V2 organise tout autour d'un **schéma** unique. Cette section suit ce même schéma : chaque concept y est défini une fois, simplement, dans le même **langage ubiquitaire** que le code (kernel/noyau, miroir, cliquet, mur — gardés tels quels). Lisez-la dans l'ordre, et vous descendez la chaîne complète d'AIDOS.

<Warning>
**« BDD » ne veut jamais dire « la base de données ».** Ici **BDD = Behavior-Driven Development**, la méthode (`Given / When / Then` avant le code). La base, elle, s'appelle toujours **Postgres**.
</Warning>

## Comment lire cette section

1. **Dans l'ordre** : chaque page suppose la précédente. L'idée précède le mur, le mur précède le kernel, etc.
2. **Une notion par page** : court, accessible, sans code.
3. **Les mots sont gardés tels quels** : kernel, miroir, cliquet, mur, verticale, facette — ce sont des mots de vérité, on ne les traduit pas.
