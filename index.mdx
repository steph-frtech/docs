**AIDOS** est un *AI Development Operating System* : un système qui fait écrire le code par l'IA tout en gardant la **vérité** entre des mains humaines. Il met en œuvre la méthode **KRD** (*Kernel-Ratchet Development*) : un petit noyau de vérité exécutable, du code librement réécrit par l'IA que le **cliquet** ne laisse jamais régresser, et un **miroir** qui prouve chaque vérité.

<Note>
  Cette documentation est écrite pour **deux lecteurs**. Choisissez votre porte d'entrée — les deux racontent la même histoire, à deux profondeurs.
</Note>

## Les deux mandats

AIDOS repose sur deux règles non négociables :

<CardGroup cols={2}>
  <Card title="Mandat A — la preuve avant le code" icon="vial">
    Aucune ligne de code sans un scénario rouge d'abord. Le miroir (BDD) *est* la spécification du comportement. `rouge → vert → refactor`.
  </Card>
  <Card title="Mandat B — la vérité vit dans Postgres" icon="database">
    Toute la vérité et sa méta vivent dans Postgres (content-addressed, append-only), hors de portée de l'agent. Le code n'en est qu'une projection.
  </Card>
</CardGroup>

## Comment lire les étapes

AIDOS se construit étape par étape (`S00`, `S01`, …). Chaque étape ajoute **une seule** capacité vérifiable, et publie **deux pages** ici :
