## Méta

Les vérités et miroirs que la piste FK devra prouver, tels que décidés au grill :

- **Le doc-miroir est jugé par calcul** : s9/s10 sont *dérivées* déterministiquement du code/AST ; la comparaison s2↔s9 est **ensembliste** (concepts du lexique, behaviors énumérés, erreurs couvertes). Divergence structurelle = **bloquante** ; prose = **advisory** (un LLM signale, n'arbitre jamais). Miroir : fault-injection — retirer un behavior du code rougit la paire ; éditer la prose seule ne bloque pas.
- **La parité du niveau de vérité** : `truth_level` est stocké mais écrit uniquement par la fonction de transition déterministe ; le miroir `stored_level == computed_level` rougit sur toute divergence — le stockage est un cache prouvé du calcul, jamais une seconde source.
- **La conscience n'invente aucun verdict** : property — son rapport ne contient que des verdicts *sourcés* des juges existants (runner, complétude, SemanticDiff, RealityMirror, senseurs, ledger) ; mêmes verdicts d'entrée → même rapport.
- **L'autonomie monte par preuve** : property — la promotion A0→A8 est une fonction pure de l'historique AgentRun ; A8 inatteignable sur action critique.
- **L'incompressible** : fault-injection — un kernel sans s1 ou sans paire de preuve (s4↔s5/s6) est un monstre ; un kernel-feuille légalement effondré passe.
- **Expand-contract E0-E7** : property — le mapping N→E est total (même miroir → même E) ; la phase contract ne perd aucun miroir (N déprécié via lifecycle, jamais supprimé).

## Méta-méta

- **La place dans le cliquet.** FKE ne touche ni le mur ni la fitness : il **renforce la loi de complétude** (de « une vérité ↔ un miroir vivant » vers « quatre familles de paires + gabarit effondrable ») — un garde-fou ne peut qu'être AJOUTÉ, jamais retiré (méta-loi §5). Le minimum incompressible garantit que le gabarit n'affaiblit rien : il étend la loi sans l'amollir.
- **L'anti-Goodhart tenu.** Les deux tentations écartées au grill sont exactement celles que §8 vise : un *jugement LLM* des doc-miroirs (le juge doit être déterministe) et une *conscience-évaluatrice* (le « second agent qui valide » n'est pas une preuve). Les deux sont réduites au rôle d'advisory, re-vérifiées par le calcul.
- **L'honnêteté v8.1.** Par la formule du Tome (« un concept n'est accepté que s'il possède définition, record, propagation, hook et exemple »), le LIVRE XXX entre avec **définition + exemples** ; ses **records/hooks/propagations** arrivent par FK01-FK10 — d'ici là, les deltas sont des OpenQuestions datées, pas des vérités opérantes.
- **Les décisions** : ADR 0044 (les huit forks, alternatives rejetées incluses) ; termes canoniques au §161 du Tome (FKE, conscience, paire-miroir, kernel effondré, Vibe Lab, Promotion Gate) ; placement au §162 (→ Livre XXX) ; glossaire partagé dans `CONTEXT-MAP.md`.
- **La frontière constructrice/construite inchangée** : AIDOS reste Go (ADR 0040), l'app émise reste Hono/TS fonctionnel + IaC Pulumi/TS (ADR 0043) — FKE les décrit tous deux comme instances de la même anatomie, à travers les plans (fractalité).
