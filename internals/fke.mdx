## Méta

Les vérités et miroirs que la piste FK devra prouver :

- **L'anatomie 1-pour-1.** Six paires déclaré↔prouvé (Spec↔Doc · Comportement↔Résultats · Scénarios↔Tests · Modèle↔Projection · Contrat↔Code · Evidence-attendue↔observée). Property — chaque vérité déclarée a EXACTEMENT un reflet prouvé ; le Contrat apparie le Code (plus d'orpheline) ; le code optionnel **par émission**, pas par absence de partenaire.
- **8 facettes, croisées ISO 25010** (F·I·S·B·R·V·M·X), effondrables. Property — un kernel n'instancie une facette que s'il porte cette nature de vérité (F toujours présente) ; chaque facette = le même squelette de 6 paires sous son angle. **Complétude facet-aware** : une paire requise manquante/divergente de toute facette = monstre.
- **Le doc-miroir jugé par calcul** : s9/s10 dérivées déterministiquement du code/AST ; comparaison s2↔s9 **ensembliste** (lexique, behaviors, erreurs). Divergence structurelle **bloquante** ; prose **advisory** (un LLM signale, n'arbitre jamais). Fault-injection — retirer un behavior rougit la paire ; éditer la prose seule ne bloque pas.
- **Parité du `truth_level`** : stocké mais écrit uniquement par la transition déterministe ; miroir `stored_level == computed_level` (divergence = rouge) — un cache prouvé du calcul, jamais une 2ᵉ source.
- **La conscience n'invente aucun verdict** : property — son rapport ne contient que des verdicts *sourcés* des juges existants (runner, complétude, SemanticDiff, RealityMirror, senseurs, ledger) ; mêmes verdicts → même rapport. Aucun nouveau juge.
- **Le WhyTree finit en miroir** : fixture — chaque cause du WhyTree est reproductible (sinon rejetée — anti-confabulation) ; un WhyTree sans miroir terminal est refusé (`WHYTREE_NO_MIRROR`) ; property — la remontée sur `caused_by` est déterministe.
- **L'autonomie monte par preuve** : property — A0→A8 est une fonction pure de l'historique AgentRun ; A8 inatteignable sur action critique.
- **Expand-contract E0-E7** : property — le mapping N→E est total ; la phase contract ne perd aucun miroir (N déprécié via lifecycle, jamais supprimé).

## Méta-méta

- **Les deux axes (FKE-1.4).** Une vérité a deux coordonnées : sa **facette** (NATURE — axe orthogonal, qui *sépare* : régler la sécurité ne touche pas la perf) et son **niveau** dans la verticale produit→entité (axe latéral, qui *couple* : une vérité basse contraint ses rungs SOURCE au-dessus, et le red wave REMONTE cette ligne). Coordonnées complètes : niveau × facette × côté-du-mur × échelle-fractale.
- **La causalité dans les deux sens.** Le red wave (§42) propage AVANT (cause→effets) ; le **WhyTree** (FKE-35.1) remonte ARRIÈRE (effet→cause racine) sur le lien `caused_by`. C'est le 5-pourquoi **redressé** : pas une facette (geste du loopback, transversal) ; déterministe sur le graphe ; LLM gaté + cause vérifiée ; un arbre (fishbone) ; terminaison en miroir.
- **La place dans le cliquet.** FKE ne touche ni le mur ni la fitness : il **renforce la loi de complétude** (de « une vérité ↔ un miroir vivant » vers « toutes les paires de toutes les facettes instanciées ») — un garde-fou ne peut qu'être AJOUTÉ, jamais retiré (méta-loi §5). L'incompressible (intention + paire de preuve) garantit que le gabarit effondrable n'amollit rien.
- **L'anti-Goodhart tenu.** Toutes les tentations de juge-non-déterministe ont été écartées : doc-miroirs jugés structurellement (prose advisory) ; conscience = agrégateur (aucun second juge) ; WhyTree = graphe + cause reproduite ; facette X = soft (informe, ne bloque pas — pas de sur-contrainte UX, l'erreur symétrique §13.4). Le juge reste le miroir déterministe (§8).
- **La fermeture par construction + croisement externe.** Le modèle des facettes est **clos à 8** non par fatigue mais par un **test de décision** (facette intrinsèque vs arête vs sous-lentille vs propriété de graphe/changeset) **croisé contre ISO 25010** — qui a révélé deux oublis (R fiabilité, X expérience) en plus du 2ᵉ cliquet (M). Note : I (Invariants ∀) est un axe de **rigueur de preuve**, pas un attribut ISO.
- **L'honnêteté v8.1.** Par la formule du Tome, le LIVRE XXX entre avec **définition + exemples** ; ses **records/hooks/propagations** arrivent par FK01-FK16 — d'ici là, des OpenQuestions datées, pas des vérités opérantes.
- **Les décisions** : ADR 0044 (fusion + 8 forks) + ADR 0045 (anatomie complète) ; termes canoniques §161 (FKE, conscience, paire-miroir, facette, kernel effondré, Vibe Lab, Promotion Gate, pipeline VIBE AI LAB, WhyTree, caused_by, les deux axes) ; placement §162 (→ Livre XXX) ; glossaire partagé `CONTEXT-MAP.md`.
- **Frontière constructrice/construite inchangée** : AIDOS reste Go (ADR 0040), l'app émise reste Hono/TS + IaC Pulumi/TS (ADR 0043) — FKE les décrit tous deux comme instances de la même anatomie (fractalité à travers les plans).
